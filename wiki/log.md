日志只记录知识摄入、查询、检查和契约变化，不记录当天行情或可由代码重算的事实。

- 以当前全部 `KNOWLEDGE_INDEX` 编译 `knowledge_manifest.v1`。
- 新增 `knowledge_trace.v1`，保存目标日、事实指纹、来源指纹、得分、事实路径和影响边界。

- 编排路径在动作判断完成后生成引用轨迹，并随正式快照冻结，供 replay 原样复用。

## [2026-07-17] contract | 收紧事实来源与日报快照

- 公共 trace 入口与 `knowledge_hit_facts` 使用同一字段白名单；未知根路径和内层路径都拒绝进入路由。
- 每条事实来源只保留规范化的 `derived` 或 `explicit` 说明及对应输入路径，不接受调用方伪造的来源标识。
- fresh 日报只在知识清单、引用轨迹、日期和指纹完整时保存快照；replay 继续保留明确的历史缺失说明。
- 明日动作与条件先展示，经验库引用和市场语言研究证据后展示；完整知识轨迹只留在结构化产物中。

## [2026-07-17] contract | 收紧冻结轨迹日期一致性

- 冻结时再次检查调用参数、context 与 trace 的目标日和查询日，日期必须是规范且真实存在的 `YYYY-MM-DD`。
- context 与 trace 的日期必须逐字段一致；即使重新计算出自洽指纹，非法或错位日期也不能进入快照或 replay。

## [2026-07-17] contract | 补齐来源诊断与复核置信度

- 预期来源即使没有被当前运行条目引用，也保存明确的元数据状态；缺少来源日期、采集日期或原文位置时生成稳定提醒。
- context 顶层直接暴露已找到来源，同时保留旧 `source_paths`。
- hook、fresh runtime 与 replay 共用同一可用性到数值置信度映射；缺失历史轨迹时引用与复核置信度都降为 `0.0`。
- entry 引用与全局来源索引的日期、原文位置和元数据状态必须一致；自洽指纹不能掩盖两处来源说明分叉。
- hook 缺少知识清单、清单不是 Mapping、清单内部列表或枚举字段类型非法，或外层提醒字段类型非法时，稳定返回空引用和明确提醒并降为 `0.0`；validator 与 trace 路由直接收到非 Mapping 时也返回类型诊断，不异常退出。清单自报不可用但未附原因时补稳定提醒。来源变化的 replay 以独立字段保留冻结可信度，重复 replay 继续复用原轨迹。

## [2026-07-17] contract | 收紧事实条件与零命中解释边界

- manifest 与 router 共用同一组精确事实路径；父路径和未登记路径不能放宽结构化确认条件。
- 公共 trace 路由收到非 Mapping facts 时返回空命中和稳定诊断，不异常退出。
- context 收到畸形清单列表字段时保留类型诊断并降为 `0.0`，不直接展开非法值。
- 每个 trace 即使零命中或历史轨迹缺失，也在顶层保留 `explanation_only` 和不得影响的正式决定字段；缺少该边界的 fresh 轨迹不能冻结。
