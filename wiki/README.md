# LLM Wiki

这个目录是日报 skill 的中文知识层：人可读，AI可引用。它不替代代码，不替代 replay，不替代市场数据，只保存已经被确认过、可复用、需要避免认知漂移的交易知识。

- [知识导航](index.md)
- [操作日志](log.md)

## 节点分区

- `交易思想`：交易底层原则、价格行为字段、缠论结构语言、日报使用边界。
- `个股分析`：个股结构观察模板，服务于候选股判断和交易复盘。
- `板块补充`：板块、主线、扩散、持续性与个股结构之间的关系。
- `个股炒作逻辑复盘`：事件、情绪、结构和失败条件的复盘模板。
- `资料库`：原文、外部资料和历史材料的索引。资料库只做来源定位，不直接进入日报主链。
- `运行契约`：日报生成、数据源优先级、事实入库、LLM Wiki 维护与路由等可执行工作流规则。

## 写入边界

- 稳定知识写入 LLM Wiki：反复确认的交易思想、缠论定义、日报字段映射、结构模板。
- 一次性教训写入反思：某次任务的错误、某次生成的坑、一次性操作提醒。
- skill 只写行为契约：何时加载 wiki、如何保持日报口径、如何验证输出。
- service/code 写运行逻辑：市场感知投影、市场光合作用、金额计算、结构计算等可执行逻辑都应在 service 层或代码里维护。

## 使用方式

日报 skill 使用 wiki 时，只取字段化结论，不把理论长文搬进日报。默认顺序是：

1. 先看 `wiki/交易思想/价格行为与能量框架.md`，确认个人交易底层；遇到低回撤、攻击频次、亏损边界、“别输在数学上”、当下执行、未来焦虑、短线当下性、追涨杀跌、买点质量、趋势地基、盈亏同源点、股性过滤、尾盘归因、小作文校准、消息强化项或用远期想象压迫盘中动作的问题也先读这里。遇到布鲁克斯价格行为、趋势/交易区间、始终入场、二次入场、信号K线、急速与通道、交易者等式、量价、成交量、资金表态、叙事后置、按图索因或基本面解释时，同时读取 `wiki/交易思想/布鲁克斯价格行为趋势.md`。
2. 再看 `wiki/交易思想/判断样本与市场演变.md`，确认日报不是预测确定答案，而是沉淀可验证的判断样本；遇到预测崇拜、每天一个个股、踩准节拍、应对剧本、量化行为博弈、散户行为模式、连接感、第一动作、B1参与权或B2确认权时，也先读这里。
3. 遇到 AI 使用、知识节点、知识复利、个人护城河或复利方向判断时，读取 `wiki/交易思想/AI摩擦与知识复利.md`。
4. 遇到外部资料摄入、知识节点维护、wiki 回答反哺、本地检索/RAG、LLM Wiki 分工、节点路由，或需求变更/日报生成需要同时生成 `AGENTS.md` / `flow.md` / `testing.md` / `readme.md` 四个伴随文件时，读取 `wiki/运行契约/LLM Wiki维护与路由契约.md`。
5. 遇到供应链瓶颈、产业链拆解、AI硬件上游、CPO、光通信、InP衬底、关键材料、产能稀缺或外部大神方法论转本地框架时，读取 `wiki/板块补充/供应链瓶颈研究法.md`。
6. 遇到启动板、趋势仓、卖飞复盘或短中结合问题时，读取 `wiki/交易思想/启动板与趋势持股短板.md`。
7. 处理 `明日极度看好`、参与窗口或判断账本时，读取 `wiki/交易思想/极度看好参与时机.md`。
   - 用户可见买卖动作只认 `09:30-09:35`、`09:50-10:10`、`14:30-14:55`；结构观察语言不能写成参与窗口。
8. 遇到候选质量、扣分、动作分层、盘中问股继承日报结论、外部认同型交易、找观点确认、顺风放大自信或逆风找人评理时，读取 `wiki/交易思想/扣分系统与动作分层.md`。
9. 遇到账户本金、688开头标的、一手金额过高、`实际可买` / `实际不可买` 时，读取 `wiki/交易思想/实际账户情况.md`。
10. 遇到做T、小资金正T/倒T、同股T、已有1x同股继续、2B法、B1/B2、参与权/确认权、必须买够、怕小赚、临时2x、强表态失败、跌破VWAP/昨收/MA7、买回确认、市场修复兜底复盘、连续盈利后失控、顺境收紧、两笔出问题停手或股池风向标时，读取 `wiki/交易思想/做T与风险控制.md`。
   - 正式 spec：`docs/trellis/specs/2026-05-31-sniper-trading-strategy-design.md`
11. 遇到换仓、亏损后追新方向、同股T亏损、盘中临时全仓切换、把态度误当仓位、把强表态当买入资格或尾盘卖出规则误用到失败样本时，读取 `wiki/交易思想/交易错题本.md`。
12. 遇到新股、次新、C阶段或情绪出口判断时，读取 `wiki/交易思想/新股周期与市场情绪.md`。
13. 遇到低位缩量横盘、突放巨量、涨停/炸板、二次启动、无公开题材异动、龙头开盘0轴/分时黄线强弱、尾盘下杀、特殊节点隔日确认、龙头分歧日、首阴日、龙回头支撑日、周五风险、异动监管、老龙未死不做新龙、龙头急跌后急拉、加速风险、核买核卖博弈、日K关键位置、关键位跌停次日验证、跌停N字观察、关键位作废、龙头心态纪律、节奏踏错、同手同脚、合理空仓、节奏复位空仓、延后确认空仓、错失待批改、公共合理不等于超短边际、风格切换载体、主线真空期、旧目标强弩之末、旧信号源批改、周五信号源、周一空仓或周二再强问题时，读取 `wiki/交易思想/价格行为与能量框架.md`。
14. 遇到结构性行情、水池九宫格、先选板块、板块节奏、量化轮动、主线延续、单一龙头定价权、中军持续性、名字辨识度、板块高标反馈、抱团环境、板块指数走坏、反弹质量、主动做多、主动带动反弹、跟随指数反弹、熟悉资产修复、减亏离场、指数深V、先于指数、节奏不匹配、共振待确认、被动下跌、冰点接冰点、值博率、早信、无人问津、鱼身、人声鼎沸、龙头二次发力、赛道偏离、拥挤兑现、高位设备材料减仓压力、边际主线、空仓后新主线复核、外盘主线传导、外盘拉升、存储大涨、业绩线、轮动线、科技线牵制、主攻点切换或 A 股同链映射确认问题时，读取 `wiki/板块补充/板块中枢与主线延续.md`。
15. 遇到行业、概念、板块 tag 维护，或需要判断当前上涨板块、主 tag、辅助 tag、噪音 tag、反证 tag 时，读取 `wiki/板块补充/实时Tag池维护与使用.md`。
16. fresh daily generation 先看 `wiki/运行契约/日报数据源契约.md`，确认 Tushare-first。
17. 遇到指数强但赚钱效应弱、成交额高位但扩散差、对立反弹、老主线疲态或题材荒时，读取 `wiki/板块补充/板块中枢与主线延续.md` 与 `wiki/交易思想/AI摩擦与知识复利.md`，先生成 `市场结构判断`，再决定是否输出 `知识复利提示`。
18. 遇到量化踩踏、程序化卖出、鸭蛋弧、根号曲线、越跌越快、Hawkes、订单流失衡或单位成交价格冲击时，先读 `wiki/资料库/异质临界值触发与流动性反馈模型.md`；需要核对具体案例时，再分别读取 `wiki/资料库/2026-07-10兆易创新极端资金样本.md` 与 `wiki/资料库/2026-05-21上证指数级联下跌样本.md`。
   - 曲线只描述价格输出，不单独确认量化身份；先区分局部外形、整段过程和真实机制。
19. 遇到烧柴理论、叶火与炭火、快流慢流、瞬时爆量、资金持续性、压力半衰期、量化退潮或“干柴是否点着大木头”时，读取 `wiki/资料库/烧柴理论-资金压力的峰值库存与半衰期.md`。
   - 快慢由触发条件、证据记忆、执行参与率和剩余库存共同决定，不把“量化”和“大资金”写成互斥账户类别。
20. 遇到市场语言、资金合力、量化启动/扩散/拥挤/衰减/踩踏/修复、买方合力低风险参与区、卖方合力高位衰减区、指数与全市场合力的区别，或固定时间钟与事件时间钟怎样配合时，读取 `wiki/交易思想/市场语言翻译与资金合力阶段.md`。
   - 市场语言只翻译范围、方向、阶段、证据、反证和下一窗口任务；曲线外形不确认账户身份，事件时间不新增买卖窗口。
21. 遇到量化跟踪日报如何选公式、公式能得出什么结论、鸭蛋弧怎样服务日报、持续加速与边际衰减如何区分，或需要设计程序化压力候选字段时，读取 `wiki/资料库/量化跟踪日报公式工具箱.md`。
   - 日报运行层只保留一套压力阶段模型；根号/椭圆、指数、Gompertz和对数留在 replay 与研究解释层，`q/L`与恢复力负责机制解释。
22. 再看 `wiki/交易思想/缠论体系.md`，确认缠论在本系统里的定位。
23. 生成日报、摘要、诊断或日志时，遵守 `wiki/交易思想/日报术语契约.md`。
24. 遇到中枢、背驰、买卖点、级别问题时，读取对应中文节点。
25. 需要追原文时，只通过 `wiki/资料库/缠论原文索引.md` 找来源。

核心原则：中文节点先服务人的理解，再服务模型引用。
