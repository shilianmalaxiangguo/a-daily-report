# LLM Wiki

这个目录是日报 skill 的中文知识层：人可读，AI可引用。它不替代代码，不替代 replay，不替代市场数据，只保存已经被确认过、可复用、需要避免认知漂移的交易知识。

## 节点分区

- `交易思想`：交易底层原则、价格行为字段、缠论结构语言、日报使用边界。
- `个股分析`：个股结构观察模板，服务于候选股判断和交易复盘。
- `板块补充`：板块、主线、扩散、持续性与个股结构之间的关系。
- `个股炒作逻辑复盘`：事件、情绪、结构和失败条件的复盘模板。
- `资料库`：原文、外部资料和历史材料的索引。资料库只做来源定位，不直接进入日报主链。
- `运行契约`：日报生成、数据源优先级、发布链路等可执行工作流规则。

## 写入边界

- 稳定知识写入 LLM Wiki：反复确认的交易思想、缠论定义、日报字段映射、结构模板。
- 一次性教训写入反思：某次任务的错误、某次生成的坑、一次性操作提醒。
- skill 只写行为契约：何时加载 wiki、如何保持日报口径、如何验证输出。
- service/code 写运行逻辑：市场感知投影、市场光合作用、金额计算、结构计算等可执行逻辑都应在 service 层或代码里维护。

## 使用方式

日报 skill 使用 wiki 时，只取字段化结论，不把理论长文搬进日报。默认顺序是：

1. 先看 `wiki/交易思想/价格行为与能量框架.md`，确认个人交易底层；遇到低回撤、攻击频次、亏损边界或“别输在数学上”类问题也先读这里。
2. 再看 `wiki/交易思想/判断样本与市场演变.md`，确认日报不是预测确定答案，而是沉淀可验证的判断样本。
3. 遇到启动板、趋势仓、卖飞复盘或短中结合问题时，读取 `wiki/交易思想/启动板与趋势持股短板.md`。
4. 处理 `明日极度看好`、参与窗口或 snap-ui 判断账本时，读取 `wiki/交易思想/极度看好参与时机.md`。
5. 遇到换仓、亏损后追新方向、盘中临时全仓切换时，读取 `wiki/交易思想/交易错题本.md`。
6. 遇到新股、次新、C阶段或情绪出口判断时，读取 `wiki/交易思想/新股周期与市场情绪.md`。
7. 遇到板块节奏、量化轮动、主线延续或单一龙头定价权问题时，读取 `wiki/板块补充/板块中枢与主线延续.md`。
8. fresh daily generation 先看 `wiki/运行契约/日报数据源契约.md`，确认 Tushare-first。
9. 推送 snap-ui 或处理 Cloudflare Pages 问题前，先看 `wiki/运行契约/snap-ui发布契约.md`。
10. 再看 `wiki/交易思想/缠论体系.md`，确认缠论在本系统里的定位。
11. 生成日报、摘要、诊断或日志时，遵守 `wiki/交易思想/日报术语契约.md`。
12. 遇到中枢、背驰、买卖点、级别问题时，读取对应中文节点。
13. 需要追原文时，只通过 `wiki/资料库/缠论原文索引.md` 找来源。

核心原则：中文节点先服务人的理解，再服务模型引用。
