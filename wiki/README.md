# LLM Wiki

这个目录是日报 skill 的中文知识层：人可读，AI可引用。它不替代代码，不替代 replay，不替代市场数据，只保存已经被确认过、可复用、需要避免认知漂移的交易知识。

## 节点分区

- `交易思想`：交易底层原则、价格行为字段、缠论结构语言、日报使用边界。
- `个股分析`：个股结构观察模板，服务于候选股判断和交易复盘。
- `板块补充`：板块、主线、扩散、持续性与个股结构之间的关系。
- `个股炒作逻辑复盘`：事件、情绪、结构和失败条件的复盘模板。
- `资料库`：原文、外部资料和历史材料的索引。资料库只做来源定位，不直接进入日报主链。
- `运行契约`：日报生成、数据源优先级、事实入库、LLM Wiki 维护与路由等可执行工作流规则。

## 写入边界

- 稳定知识写入 LLM Wiki：反复确认的交易思想、缠论定义、日报字段映射、结构模板。
- 一次性教训写入反思：某次任务的错误、某次生成的坑、一次性操作提醒。
- skill 只写行为契约：何时加载 wiki、如何保持日报口径、如何验证输出。
- service/code 写运行逻辑：市场感知投影、市场光合作用、金额计算、结构计算等可执行逻辑都应在 service 层或代码里维护。

## 使用方式

日报 skill 使用 wiki 时，只取字段化结论，不把理论长文搬进日报。默认顺序是：

1. 先看 `wiki/交易思想/价格行为与能量框架.md`，确认个人交易底层；遇到低回撤、攻击频次、亏损边界、“别输在数学上”、当下执行、未来焦虑、短线当下性、追涨杀跌、买点质量、趋势地基、盈亏同源点、股性过滤或用远期想象压迫盘中动作的问题也先读这里。遇到布鲁克斯价格行为、趋势/交易区间、始终入场、二次入场、信号K线、急速与通道、交易者等式、量价、成交量、资金表态、叙事后置、按图索因或基本面解释时，同时读取 `wiki/交易思想/布鲁克斯价格行为趋势.md`。
2. 再看 `wiki/交易思想/判断样本与市场演变.md`，确认日报不是预测确定答案，而是沉淀可验证的判断样本。
3. 遇到 AI 使用、知识节点、知识复利、个人护城河或复利方向判断时，读取 `wiki/交易思想/AI摩擦与知识复利.md`。
4. 遇到外部资料摄入、知识节点维护、wiki 回答反哺、本地检索/RAG 与 LLM Wiki 分工或节点路由问题时，读取 `wiki/运行契约/LLM Wiki维护与路由契约.md`。
5. 遇到供应链瓶颈、产业链拆解、AI硬件上游、CPO、光通信、InP衬底、关键材料、产能稀缺或外部大神方法论转本地框架时，读取 `wiki/板块补充/供应链瓶颈研究法.md`。
6. 遇到启动板、趋势仓、卖飞复盘或短中结合问题时，读取 `wiki/交易思想/启动板与趋势持股短板.md`。
7. 处理 `明日极度看好`、参与窗口或判断账本时，读取 `wiki/交易思想/极度看好参与时机.md`。
   - 用户可见买卖动作只认 `09:30-09:35`、`09:50-10:10`、`14:30-14:55`；结构观察语言不能写成参与窗口。
8. 遇到候选质量、扣分、动作分层、盘中问股继承日报结论时，读取 `wiki/交易思想/扣分系统与动作分层.md`。
9. 遇到账户本金、688开头标的、一手金额过高、`实际可买` / `实际不可买` 时，读取 `wiki/交易思想/实际账户情况.md`。
10. 遇到做T、小资金正T/倒T、买回确认、市场修复兜底复盘、连续盈利后失控、顺境收紧、两笔出问题停手或股池风向标时，读取 `wiki/交易思想/做T与风险控制.md`。
   - 正式 spec：`docs/trellis/specs/2026-05-31-sniper-trading-strategy-design.md`
11. 遇到换仓、亏损后追新方向、盘中临时全仓切换时，读取 `wiki/交易思想/交易错题本.md`。
12. 遇到新股、次新、C阶段或情绪出口判断时，读取 `wiki/交易思想/新股周期与市场情绪.md`。
13. 遇到低位缩量横盘、突放巨量、涨停/炸板、二次启动、无公开题材异动、龙头开盘0轴/分时黄线强弱、尾盘下杀、特殊节点隔日确认、龙头分歧日、首阴日、龙回头支撑日、周五风险、异动监管、老龙未死不做新龙、龙头急跌后急拉、加速风险、核买核卖博弈或龙头心态纪律问题时，读取 `wiki/交易思想/价格行为与能量框架.md`。
14. 遇到结构性行情、水池九宫格、先选板块、板块节奏、量化轮动、主线延续、单一龙头定价权、中军持续性、名字辨识度、板块高标反馈或抱团环境问题时，读取 `wiki/板块补充/板块中枢与主线延续.md`。
15. 遇到行业、概念、板块 tag 维护，或需要判断当前上涨板块、主 tag、辅助 tag、噪音 tag、反证 tag 时，读取 `wiki/板块补充/实时Tag池维护与使用.md`。
16. fresh daily generation 先看 `wiki/运行契约/日报数据源契约.md`，确认 Tushare-first。
17. 遇到指数强但赚钱效应弱、成交额高位但扩散差、对立反弹、老主线疲态或题材荒时，读取 `wiki/板块补充/板块中枢与主线延续.md` 与 `wiki/交易思想/AI摩擦与知识复利.md`，先生成 `市场结构判断`，再决定是否输出 `知识复利提示`。
18. 再看 `wiki/交易思想/缠论体系.md`，确认缠论在本系统里的定位。
19. 生成日报、摘要、诊断或日志时，遵守 `wiki/交易思想/日报术语契约.md`。
20. 遇到中枢、背驰、买卖点、级别问题时，读取对应中文节点。
21. 需要追原文时，只通过 `wiki/资料库/缠论原文索引.md` 找来源。

核心原则：中文节点先服务人的理解，再服务模型引用。
