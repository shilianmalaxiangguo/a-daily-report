# 交易 Wiki

**为了赚钱理解市场，不为了维护一套理论解释市场。**

## 当前只执行什么

当前唯一主策略是 [[交易思想/小盘轮换策略|小盘轮换 v0.3]]：每20个交易日换手、5只名单加3只备选、主板和创业板、收盘相对原买价上涨10%后次日开盘卖，止盈现金留到下次换手。账户净值底线为初始本金的0.7，不上杠杆。

账户按1万元示例，**佣金万一免五：成交额的0.01%，无最低收费**；过户费、卖出印花税另计。实际持仓、现金和原买价尚未提供，名单和模拟不等于成交。

当前评价只看最近20个月：2025-02-28至2026-10-29。更早样本只作历史资料；换手日历仍从2024-07-01锚定，日历起点不等于评价窗口。

## 保留但不进入日报执行的研究

阿尔法／贝塔的模型、历史规则、回测输入、独立复算和冻结结果继续保留，供单独研究和比较。它们不进入小盘日报的名单、换手、仓位或卖出流程；研究结果不能覆盖小盘 v0.3 的现行规则。

## 淘汰赛的结论

板块资金扩散淘汰赛暂保留为历史观察材料。它没有完整的买卖、成交和账户规则，冻结记录也不足20个月，目前不能和小盘轮换公平比较收益。它不参与小盘选股、择时或资金分配；旧个股漏斗不恢复为当前策略。

## 已退出当前使用

阿尔法六项买入检查、高贝塔篮子、防守/进攻阶段买卖、五日退出与对账、成长指数趋势组合、龙头接力和其他旧候选，不再日更或作为当前建议；阿尔法／贝塔研究代码和历史证据仍按上节保留。基础行情、财报、来源校验和指数对照继续为小盘与市场观察提供数据。

历史报告、快照、旧检验与源码供查证，不因保留就继续有效；旧文件的“现行”、旧PRD和旧测试均不能覆盖本页。旧方法详见 [清理前资料](../docs/archive/current-strategy/2026-11-01/README.md)，日常任务不默认加载。

不以月收益目标选参数；做好下一次名单、真实成交和复核，利润仍受市场、成本与随机性影响。回测支持继续检验，不能保证稳定盈利，也不能保证净值绝不穿过0.7。
