# 腾讯当日分时接口使用说明

## 一、结论

截至 `2026-07-30` 实测，腾讯财经的以下公开 Web 接口可返回沪深普通 A 股的最新交易日分时：

```text
https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=<腾讯证券代码>
```

例如：

```text
https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh603986
https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sz000001
```

这个接口适合：

- 查询当前或最新交易日的分时价格点。
- 查询截至各时点的累计成交量和累计成交额。
- 计算分时累计均价，或用相邻点差值观察新增量额。
- 对其他一分钟数据源做当日或近期交叉核对。

它不适合：

- 按请求参数指定任意历史日期。
- 直接产生一分钟 `open/high/low/close` K 线。接口只给出各时点价格，不给每分钟完整 OHLC。
- 在不核对返回日期的情况下补历史日报或 replay 事实。
- 把没有实测过的指数、基金、北交所股票或其他证券直接套用普通沪深 A 股的单位规则。

该地址是腾讯网页使用的公开接口，不是本仓库可依赖的官方稳定性承诺。请求人应保留超时、有限重试、返回结构检查和交易日核对。

## 二、最小请求

### 2.1 证券代码

推荐由调用方明确传入市场前缀，不在请求时猜测：

| 市场 | 格式 | 例子 |
|---|---|---|
| 上海普通 A 股 | `sh` + 6 位代码，本文允许前缀 `600/601/603/605/688` | `sh603986` |
| 深圳普通 A 股 | `sz` + 6 位代码，本文允许前缀 `000/001/002/003/300/301` | `sz000001` |

市场前缀本身不能区分股票、指数、基金和其他证券。例如上证指数 `sh000001` 也符合“`sh` + 6 位数字”的外形，但它不能使用普通 A 股“一手等于 100 股”的单位规则。本文代码会拒绝上表允许范围之外的代码；北交所及其他证券类型需要单独实测后再定义规则。

### 2.2 curl 请求

```bash
curl --silent --show-error --location \
  --retry 2 --retry-all-errors \
  --connect-timeout 10 --max-time 30 \
  'https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=sh603986'
```

实测响应头的 `Content-Type` 是 `text/html; charset=UTF-8`，但响应体是合法 JSON。解析时应以实际响应体为准，不要因为该响应头改用 HTML 解析。

## 三、响应结构和字段

缩略后的真实响应外形：

```json
{
  "code": 0,
  "msg": "",
  "data": {
    "sh603986": {
      "data": {
        "data": [
          "0930 356.75 15005 535303375.00",
          "0931 364.00 37046 1329301516.26"
        ],
        "date": "20260730"
      },
      "qt": {},
      "mx_price": {
        "price": "",
        "mx": ""
      }
    }
  }
}
```

主数据路径：

```text
payload["data"][symbol]["data"]
```

| 字段 | 含义 | 必须检查 |
|---|---|---|
| `date` | 实际返回的交易日，格式 `YYYYMMDD` | 必须与调用方期待日期相等 |
| `data` | 分时字符串列表 | 不能为空，每行必须可解析 |

每行固定按空白分成四列：

```text
HHMM  当时价格  累计成交量（手）  累计成交额（元）
```

以 `0931 364.00 37046 1329301516.26` 为例：

- `0931`：`09:31` 时点。
- `364.00`：该时点价格；在标准分钟结束时点上，可作为该分钟收盘价交叉核对值。
- `37046`：当日截至该时点的累计成交量，单位为手。
- `1329301516.26`：当日截至该时点的累计成交额，单位为元。

对已确认一手等于 100 股的普通沪深 A 股：

```text
累计成交股数 = 累计成交量（手） * 100
累计均价 = 累计成交额 / 累计成交股数
相邻点新增成交量 = 当前累计成交量 - 上一点累计成交量
相邻点新增成交额 = 当前累计成交额 - 上一点累计成交额
```

不要把第三、四列直接当成“该分钟成交量/成交额”。它们是日内累计值。

`qt` 里有大量没有字段名的位置数组，`mx_price` 在本次实测中为空。请不要把它们的数组下标或空值当成稳定解析契约。

## 四、交易时点处理

`2026-07-30` 对沪深两只普通 A 股的收盘后实测均返回 267 个点：

```text
09:30
09:31-11:30
13:00-15:00
15:06-15:30
```

如果业务要求是与标准 A 股一分钟结束网格对齐，只取：

```text
09:31-11:30：120 点
13:01-15:00：120 点
合计：240 点
```

不要仅根据返回数量截取前 240 条；应该按 `HHMM` 显式过滤并核对完整时间网格。

还要保留三个边界：

- 盘中请求本来就只会返回已发生的时点，不能按 240 点要求完整收盘数据。
- `09:30` 已有初始累计量额。`09:31` 减 `09:30` 只是两个腾讯点之间的新增量额，不包含 `09:30` 点已累计的部分。如果要合成一分钟成交量，必须先明确开盘集合成交量的归属，不能静默丢掉。
- 240 个标准点完整，只表示 `09:31-15:00` 标准分钟网格完整。腾讯响应可能在 `15:00` 后继续返回附加点，且累计量额仍可变化；不能把 `15:00` 的累计值误称为腾讯原始响应的最终累计值。

## 五、历史日期边界

### 5.1 `minute/query` 不能当作指定日期接口

`2026-07-30` 实测下列请求全部返回 `date="20260730"` 且分时内容相同：

```text
minute/query?code=sh603986
minute/query?code=sh603986&date=20260729
minute/query?code=sh603986&day=20260729
minute/query?code=sh603986&start=20260729&end=20260729
```

说明本次观测中 `date/day/start/end` 被忽略。不论请求地址里写了什么日期，都必须用响应里的 `date` 核对真正所属交易日。

在非交易日请求时，“最新交易日”不等于自然日当天，因此不能用系统日期替代响应日期检查。

### 5.2 `day/query` 只可作近期补充观测

同域接口：

```text
https://web.ifzq.gtimg.cn/appstock/app/day/query?code=sh603986
```

`2026-07-30` 实测返回一个列表，包含最近 5 个交易日：

```text
20260730, 20260729, 20260728, 20260727, 20260724
```

单日元素的外形是：

```json
{
  "date": "20260729",
  "data": ["0930 ...", "0931 ..."],
  "prec": "..."
}
```

本文不使用 `prec` 字段，也不把它纳入解析契约。“最近 5 个交易日”只是当前实测和本仓库既有研究记录，不是腾讯对保留天数的稳定承诺。使用时应遍历元素并按 `date` 匹配；如果找不到目标日期，就明确记录缺失，不能用其他日期替代。

## 六、可直接运行的 Python 3.14 示例

这份示例只使用 Python 标准库，输出标准交易分钟点的 JSON。金额和价格保留为字符串，避免二进制浮点误差。

```python
import argparse
import json
import re
import sys
import time
from decimal import Decimal, InvalidOperation
from urllib.error import HTTPError, URLError
from urllib.parse import urlencode
from urllib.request import Request, urlopen


ENDPOINT = "https://web.ifzq.gtimg.cn/appstock/app/minute/query"
MAX_RESPONSE_BYTES = 2_000_000
SH_A_SHARE_PREFIXES = ("600", "601", "603", "605", "688")
SZ_A_SHARE_PREFIXES = ("000", "001", "002", "003", "300", "301")


def minute_range(start_hhmm, end_hhmm):
    start = int(start_hhmm[:2]) * 60 + int(start_hhmm[2:])
    end = int(end_hhmm[:2]) * 60 + int(end_hhmm[2:])
    return [f"{value // 60:02d}{value % 60:02d}" for value in range(start, end + 1)]


EXPECTED_GRID = minute_range("0931", "1130") + minute_range("1301", "1500")
EXPECTED_GRID_SET = set(EXPECTED_GRID)


def validate_symbol(symbol):
    if re.fullmatch(r"(?:sh|sz)\d{6}", symbol) is None:
        raise ValueError(f"证券代码格式错误: {symbol!r}")

    code = symbol[2:]
    allowed_prefixes = SH_A_SHARE_PREFIXES if symbol.startswith("sh") else SZ_A_SHARE_PREFIXES
    if not code.startswith(allowed_prefixes):
        raise ValueError(f"仅支持本文限定的普通沪深 A 股代码: {symbol!r}")


def request_payload(symbol):
    url = f"{ENDPOINT}?{urlencode({'code': symbol})}"
    request = Request(
        url,
        headers={
            "Accept": "application/json",
            "User-Agent": "Mozilla/5.0",
        },
    )
    last_error = None

    for attempt in range(3):
        try:
            with urlopen(request, timeout=15) as response:
                if response.status != 200:
                    raise RuntimeError(f"HTTP {response.status}")
                body = response.read(MAX_RESPONSE_BYTES + 1)
            if len(body) > MAX_RESPONSE_BYTES:
                raise ValueError("腾讯分时响应体异常过大")
            try:
                return json.loads(body.decode("utf-8"))
            except (UnicodeDecodeError, json.JSONDecodeError) as exc:
                raise ValueError("腾讯分时响应不是有效 JSON") from exc
        except HTTPError as exc:
            raise RuntimeError(f"腾讯分时请求返回 HTTP {exc.code}") from exc
        except (URLError, TimeoutError) as exc:
            last_error = exc
            if attempt < 2:
                time.sleep(0.5 * (attempt + 1))

    raise RuntimeError("腾讯分时请求失败") from last_error


def parse_payload(payload, symbol, expected_date, require_close):
    if not isinstance(payload, dict):
        raise ValueError("腾讯分时顶层 JSON 结构错误")
    if payload.get("code") != 0 or payload.get("msg") not in ("", None):
        raise ValueError("腾讯分时接口返回失败")

    root = payload.get("data")
    node = root.get(symbol) if isinstance(root, dict) else None
    minute = node.get("data") if isinstance(node, dict) else None
    if not isinstance(minute, dict):
        raise ValueError("响应缺少目标证券的分时数据")

    actual_date = minute.get("date")
    if actual_date != expected_date:
        raise ValueError(
            f"交易日不符: expected={expected_date}, actual={actual_date!r}"
        )

    raw_rows = minute.get("data")
    if not isinstance(raw_rows, list) or not raw_rows:
        raise ValueError("腾讯分时数据为空")

    parsed = []
    previous_time_value = None
    previous_lots = None
    previous_amount = None

    for raw in raw_rows:
        fields = raw.split() if isinstance(raw, str) else []
        if len(fields) != 4:
            raise ValueError(f"分时行格式错误: {raw!r}")

        hhmm, price_text, lots_text, amount_text = fields
        if re.fullmatch(r"\d{4}", hhmm) is None:
            raise ValueError(f"分时时间格式错误: {hhmm!r}")

        hour = int(hhmm[:2])
        minute_value = int(hhmm[2:])
        if hour > 23 or minute_value > 59:
            raise ValueError(f"分时时间无效: {hhmm!r}")
        time_value = hour * 60 + minute_value

        try:
            price = Decimal(price_text)
            cumulative_lots = int(lots_text)
            cumulative_amount = Decimal(amount_text)
        except (InvalidOperation, ValueError) as exc:
            raise ValueError(f"分时数值格式错误: {raw!r}") from exc

        if price <= 0 or cumulative_lots < 0 or cumulative_amount < 0:
            raise ValueError(f"分时数值无效: {raw!r}")
        if previous_time_value is not None and time_value <= previous_time_value:
            raise ValueError(f"分时时间未严格递增: {raw!r}")
        if previous_lots is not None and cumulative_lots < previous_lots:
            raise ValueError(f"累计成交量下降: {raw!r}")
        if previous_amount is not None and cumulative_amount < previous_amount:
            raise ValueError(f"累计成交额下降: {raw!r}")

        cumulative_shares = cumulative_lots * 100
        average_price = (
            cumulative_amount / Decimal(cumulative_shares)
            if cumulative_shares
            else None
        )
        parsed.append(
            {
                "time": hhmm,
                "price": str(price),
                "cumulative_lots": cumulative_lots,
                "cumulative_shares": cumulative_shares,
                "cumulative_amount_cny": str(cumulative_amount),
                "average_price": str(average_price) if average_price is not None else None,
                "delta_lots_from_previous_point": (
                    None if previous_lots is None else cumulative_lots - previous_lots
                ),
                "delta_amount_from_previous_point": (
                    None
                    if previous_amount is None
                    else str(cumulative_amount - previous_amount)
                ),
            }
        )
        previous_time_value = time_value
        previous_lots = cumulative_lots
        previous_amount = cumulative_amount

    regular = [row for row in parsed if row["time"] in EXPECTED_GRID_SET]
    actual_grid = [row["time"] for row in regular]
    if not actual_grid:
        raise ValueError("尚无标准交易分钟数据")
    if actual_grid != EXPECTED_GRID[: len(actual_grid)]:
        raise ValueError("标准交易分钟网格缺失或错位")
    if require_close and actual_grid != EXPECTED_GRID:
        raise ValueError("收盘分时数据不完整")

    complete_standard_grid = actual_grid == EXPECTED_GRID
    latest_raw_point = parsed[-1]
    after_1500_change = None
    if complete_standard_grid:
        close_point = regular[-1]
        after_1500_change = {
            "last_raw_time": latest_raw_point["time"],
            "delta_lots_from_1500": (
                latest_raw_point["cumulative_lots"] - close_point["cumulative_lots"]
            ),
            "delta_amount_cny_from_1500": str(
                Decimal(latest_raw_point["cumulative_amount_cny"])
                - Decimal(close_point["cumulative_amount_cny"])
            ),
        }

    return {
        "provider": "tencent.appstock.minute.query",
        "symbol": symbol,
        "trade_date": actual_date,
        "complete_standard_grid": complete_standard_grid,
        "raw_point_count": len(parsed),
        "standard_point_count": len(regular),
        "latest_raw_point": latest_raw_point,
        "after_1500_change": after_1500_change,
        "rows": regular,
    }


def fetch(symbol, expected_date, require_close=False):
    validate_symbol(symbol)
    if re.fullmatch(r"\d{8}", expected_date) is None:
        raise ValueError(f"交易日格式错误: {expected_date!r}")
    return parse_payload(
        request_payload(symbol),
        symbol,
        expected_date,
        require_close,
    )


def main():
    parser = argparse.ArgumentParser(description="查询腾讯最新交易日分时")
    parser.add_argument("symbol", help="腾讯证券代码，例如 sh603986")
    parser.add_argument("expected_date", help="期待交易日，格式 YYYYMMDD")
    parser.add_argument(
        "--require-close",
        action="store_true",
        help="要求 240 个收盘标准分钟全部完整",
    )
    args = parser.parse_args()

    try:
        result = fetch(args.symbol, args.expected_date, args.require_close)
    except (RuntimeError, ValueError) as exc:
        print(str(exc), file=sys.stderr)
        return 1

    json.dump(result, sys.stdout, ensure_ascii=False, indent=2)
    sys.stdout.write("\n")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

输出里的 `rows` 只包含标准交易分钟；`complete_standard_grid` 只表示这个标准网格是否完整。`latest_raw_point` 保留腾讯原始响应的最后一点，`after_1500_change` 则在标准网格完整时显示该点相对 `15:00` 的累计量额变化。

## 七、不能省略的检查

腾讯对无效代码也可能返回 HTTP 200 和顶层 `code=0`。`sh999999` 实测返回的分时日期为空，数据行也不是四列有效结构。因此调用方至少要检查：

1. HTTP 请求成功，且 JSON 可解析。
2. 顶层 `code == 0`，`msg` 为空。
3. `data` 里存在精确的证券代码键。
4. 返回 `date` 等于期待交易日。
5. 每行恰好四列，时间、价格、累计量额均可解析。
6. 时间严格递增，累计成交量和累计成交额不下降。
7. 收盘后声明“完整”时，标准时间网格恰好为 240 点，最后一点是 `15:00`。
8. 保存或传递结果时同时保留 `provider` 和 `trade_date`，不从外层报告日期猜测数据日期。
