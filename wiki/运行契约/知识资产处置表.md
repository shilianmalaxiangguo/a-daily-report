# 知识资产处置表

## 处置决定

2026-10-21 全面重建时，`wiki/` 下原有 81 篇 Markdown 全部逐文件复制到 `docs/archive/trading-wiki/2026-10-21-before-full-rebuild/wiki/`，当前库不再保留旧正文副本。这样做不是删除历史，而是防止旧同名页面被模型读成现行规则。

- **原样归档**：字节内容和原路径保留，档案 README 与 `manifest.json` 可核对。
- **主题重写**：只把仍有用的问题、事实、定义或用户原话拆到新的少量页面；不把旧结论整段搬回来。
- **不继承**：B1/B2及改名版本、固定时窗、旧日历、固定仓位、旧仓继承、研究不得改变决定、未经证据的阈值和理论优先级。
- **隔离过期缓存**：旧 Understand Anything 图及元信息另行原样移出 Wiki，详见[缓存档案](../../docs/archive/trading-wiki/2026-10-21-retired-knowledge-graph/README.md)，不计入81篇正文。
- **不改变**：本轮不改代码、测试、配置、正式日报、快照或Obsidian插件。

“重写”不等于新页面已证明盈利；“归档”也不等于旧内容已被证实。以下表格覆盖重建前的全部 Markdown 文件。
