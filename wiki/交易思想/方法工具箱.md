# 方法工具箱

> 这页是2026-10-21重建时写的通用原则，讲怎样想，不是现在的打法。现在的打法见 [[交易思想/当前市场结构与打法]]，可照做的规则见 [[交易思想/盈利模式库]]。

工具可以直接用于形成交易判断，不再被统一限制为“只许研究”。采用某个工具也不意味着接受它的整套世界观。选择标准是它能否增加有用信息、改善结果，或者减少时间成本。

## 工具没有永久排名

| 工具 | 可以解决什么 | 使用时需要理解的代价或歧义 |
|---|---|---|
| 裸价格、K线与成交 | 描述路径、转折尝试、参与和交易位置 | 形态归类有主观性，同一外形可能有不同后续 |
| 均线、VWAP、前高前低等参考 | 约定可复算的观察位置或触发方式 | 平滑会滞后；价格反复穿越可能增加成本；触发不是因果证明 |
| MACD、KDJ 等指标 | 压缩某些变化，作为主依据或辅依据都可比较 | 多个指标可能只是同一价格的重复表达，不是多份独立证据 |
| 缠论的分解与级别 | 用一套定义组织走势、讨论中枢和背驰 | 划分版本、当时是否完成、后来重画，可能改变结果 |
| 布鲁克斯价格行为 | 从趋势、区间等背景理解信号 | 作者的频率描述不是当前 A 股样本的统计频率 |
| 板块与相对路径 | 比较集中、扩散、轮动和对象之间的差异 | 分类、成分和起点影响结论；板块解释不替代个股交易结果 |
| 产业、业绩、供需与叙事 | 识别信息变化、潜在重估和市场关注点 | 成功企业不等于买入价格合适，短线也不必等企业兑现 |
| 分段斜率、波动、压力模型 | 描述变化速度、冲击和恢复过程 | 参数选择、拟合、迟滞与缺数据都可能让解释失真 |
| 历史类比 | 提出可能路径、失败方式和替代做法 | 相似故事不等于相同条件，事后匹配不证明可预测 |
| 风格对照（规模、成长、红利） | 把收益拆成“买了什么风格”和“挑了哪只” | 这两年多小盘与成长占优；风格会反转，风格带来的收益不等于选股本事 |
| 市场模型与贝塔收缩 | 把个股涨跌分成大盘带动的部分和自己的部分 | 20日窗口的贝塔很不稳定，要向平均值收缩；独立收益显著不等于会持续，回测里之后5日反而容易回落 |
| 回测、随机对照与等权对照 | 检验一套规则过去是否比随机挑选、等权平均和指数更好 | 只覆盖一段行情和一组成本假设；从多种做法里挑最好的有偏差；2.6年里夏普差异常在误差之内 |
| 排序相关（IC）与事件检验 | 检验一个信号能否把之后表现好的股票排在前面，或某类开盘之后通常怎样走 | 不是胜率，也不是能赚多少；要看分年份是否稳定，持有期重叠时 t 要调整 |

没有“价格永远第一、基本面只负责研究、指标只能辅助”的固定分工。也不把模型复杂程度、数学符号或名人经历当作可信度排序。

## 几个仍有用的计算区别

**变化与变化的变化。** 对同一口径、等间隔序列 `x[t]`，一阶差分是 `x[t] - x[t-1]`，二阶差分是 `x[t] - 2*x[t-1] + x[t-2]`。它们描述离散变化，不证明变化会继续。间隔不同不能直接按等间隔解释，缺值也不能补零再算。

**绝对差分与增长率。** 利润增加额、利润增长率、增长率变化，是不同量；基数接近零或跨正负时，百分比尤其容易误导。价格的二阶差分、财务增速变化、同一目标期预测的上修或下修，不能都叫同一个“二阶导”然后互相替代。

**压力与库存模型。** 把冲击后恢复慢解释成未消化压力、把再次下跌解释成新的卖压，是可讨论的模型。所谓半衰期、峰值库存、临界值不是实际测得的资金身份或库存；需要说明观测量与假设之间隔着什么。

**样本内拟合与可用预测。** 看完一条路径再分段，可能很贴合，但当时未必知道下一段起止在哪里。评估实时帮助时，用当时可见部分重算，而不是把事后最优分段当作实时能力。

## 回测怎样少骗自己

2026-10-30 的回测与补充检验留下这份检查清单，具体数字见 [[交易思想/回测与检验证据]]：

- **和随机挑选比。** 同样的买卖规则和成本，每天随机挑同样只数，跑多次看分布；规则落在分布中间，就没有证明选股能力。日报的阿尔法六项检查就是这样被看清的。
- **和等权平均、成长指数比，不只和中证全指比。** 中证全指按市值加权；同期普通股票的等权平均、科创50和创业板指都涨得多，只和中证全指比会高估自己。
- **换起点。** 从2024-03-04算和从2024-01-02算，中证2000的年化相差一倍多；只有一个起点的结果不算数。
- **先算成本，再拆开看。** 5日一换的做法，成本一年约14个百分点；先看一个做法跨不跨得过成本。
- **分年份，分开样本外和设计期。** 同一规则可以一年大赚、一年大亏；设计规则时看过的那段数据，不能当成检验。
- **承认误差。** 2.6年的样本里，夏普比率本身的误差约 ±0.65；差异在误差之内的排名，不拿来换方法。
- **全部报告，不挑最好的。** 事先写定要比较哪些做法，结果全部列出；看完结果才想到的做法，写下日期，只用之后的数据检验。

## 缠论术语留什么

旧资料中的分型、笔、线段是逐层组织走势的词；理论中枢涉及连续次级别走势的重叠，不等于随手画一个横盘箱体；级别也不简单等同于分钟周期。背驰比较某一划分下的力度，三类买卖点是该理论的命名。

这些是阅读旧材料的简述，不代替原课文。具体定义、划分歧义和引用位置在 [[资料库/来源与历史档案索引]] 的缠论组。使用它们可以尝试选股或买卖，不受旧“必须等回踩”“只能辅助”的限制；但一个理论名词也不保证某段收益。

## 从过去的工具里撤掉什么

- 新高占比的固定分界，不再裁定行情阶段或次日表现。
- 仅凭三个事后案例拟合更好，不再认定分段斜率必须排第一。
- 深跌降低再次大跌可能性，不再作为默认概率判断。
- 首次突破越早观察价值越高，不再当作普遍规律。
- 双峰或双群聚，不再是解释所有 A 股行情的首要假设。
- 旧分钟参数、固定缓冲时长、固定观察期限，只在历史实现中保留。
- 阿尔法六项检查作为挑赢家的依据（2026-10-30 回测里与随机挑选差不多）；保留为观察和排除明显不合适对象的工具。
- 按最近37个决策日的前推结果开关一个方法（开与不开，之后5日几乎一样）。

撤销默认地位不等于证明相反结论正确。原公式、原参数和正反样本在档案中仍可查、可拿来比较；本轮没有重新运行这些模型，也没有宣称哪种工具已经赢了。2026-10-30 的两条撤销是检验之后的结果，同样不证明反过来做就赚钱，例如买近期最弱的，仍在待检验清单（H1）。

旧的板块深耕材料曾分别尝试量化扩散质量、识别所谓量化环境、追踪板块成交占比，并用商业航天与光模块路径、中际旭创与中芯国际作案例对照。它们留下的问题是扩散是否持续、核心与弹性是否分化、成交和成分口径怎样影响判断；旧评分、资金身份归因、窗口与数值阈值没有在本轮复算，不作为新规则。

## 怎样少用而不僵化

一个工具已经回答当前问题，就不必叠加十种同义指标。一个工具漏掉重要风险，也可以补别的信息。删减和增加都看增量价值，不把“简单”或“复杂”变成新的信仰。

尝试时可保存所用定义、数据截止时间和实际结果，方便以后比较。没有统一样本数量或先证明有效才准用的要求；不确定性照实存在，不需要用完整仪式假装消除。
