# 缠论体系

## 定位

缠论是本 skill 的结构知识库，不是新的交易系统。它用于把市场和个股走势拆成可复盘的结构字段，帮助日报稳定表达 `日线结构中枢定环境 -> 09:50-10:10窗口 -> 失效价和单笔-5%底线` 的链条。

## 本系统的使用原则

- 市场环境优先，个股结构执行。
- 指数中枢用于判断环境、仓位和是否允许参与。
- 个股结构用于判断入场、确认、止损和是否继续跟踪。
- 缠论原文不直接进入日报主链，必须先整理成中文节点和字段。
- MACD只能作为辅助，不能覆盖个人交易底层里的角度与幅度判断。

## 核心节点

- `缠论-中枢.md`：定义结构区间、震荡中轴、延伸、离开和回抽。
- `缠论-背驰.md`：判断转折风险，强调没有趋势就没有背驰。
- `缠论-分型笔线段.md`：把图形拆成可观察的基本结构。
- `缠论-买卖点.md`：一买、二买、三买以及对应失败条件。
- `缠论-级别联立.md`：日线、60分钟、30分钟之间如何分工。
- `缠论-日报使用边界.md`：哪些内容能进日报，哪些只能留在 wiki。

## 日报字段映射

| 缠论概念 | 日报字段 | 用途 |
| --- | --- | --- |
| 中枢 | `结构区间`、`箱体上沿`、`箱体下沿`、`中轴` | 判断环境和震荡位置 |
| 离开中枢 | `离开方向`、`突破有效性` | 判断是否出现方向选择 |
| 回抽不破 | `确认状态` | 判断是否进入可跟踪 |
| 背驰 | `动能衰减`、`转折风险` | 降级、止盈或避免追高 |
| 三类买卖点 | `入场资格`、`失败条件` | 决定是否允许执行 |
| 级别 | `日线环境`、`09:50-10:10窗口`、`30分钟止损`、`失效价和单笔-5%底线` | 防止不同级别信号混用 |

## 禁止漂移

- 不因为看到中枢就默认可以买。
- 不因为背驰就默认反转。
- 不把小级别背驰放大成大级别结论。
- 不把 MACD 辅助判断写成主判断。
- 不让缠论节点绕过月度攻防、市场贴合度、主线强度和仓位等级。
