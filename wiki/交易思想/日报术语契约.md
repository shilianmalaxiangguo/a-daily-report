# 日报术语契约

这页约束表达是否清楚，不规定买卖方式。报告和助手可以提出明确判断，不把所有内容写成不影响决定的研究附录。

## 说明一句话是什么

| 身份 | 合适表达 |
|---|---|
| 可追溯事实 | 什么时间、什么来源、什么口径下发生了什么 |
| 用户当前立场 | 用户明确认可什么，出处在哪里；不偷换为助手替其定的规则 |
| 助手建议 | 我倾向怎样选，依据、代价和未知是什么 |
| 来源观点 | 某作者在当时怎样解释，不替其补成已验证规律 |
| 历史记录 | 当时的判断或成交，后来怎样变化 |
| 未知或冲突 | 哪项事实不足，哪些说法无法同时成立 |

不用“谨慎”回避结论，也不用肯定语气隐藏未知。观点可以明确，证据身份不能混写。

## 词语服务问题

“主线”“核心”“强”“低位”“承接”“预期差”使用时说清所指的日期、对象或行为。没有必要为每个词发明一个固定分数；若要量化，说明计算口径，不能用漂亮数字替代含义。

价格涨跌、成交额、资金流、热度、机构席位披露是不同事实；不能互相冒充。多数 AI 输出一致，不称为市场胜率。用户偏好不称为统计结论，作者原话也不称为用户确认。

### 用户当前对阿尔法和贝塔的定义

2026-10-28 用户明确更正，此后以这次表述为准：

- **阿尔法**：个股自己的独立行情，个股涨跌与大盘方向关系不大。这里是用户的交易语言，不等于已经用统计模型证明了独立收益。
- **贝塔**：大盘涨跌带动个股共振的行情。仅有板块内部成员一起上涨，还不能称为贝塔；还要核对个股与大盘基准在同一组交易日的关系，不能凭一天同涨就断言带动关系。
- 个股与所属板块的同窗差值只是相对表现；板块成员上涨比例和中间值只是扩散事实。两者都不能未经说明直接改称阿尔法或贝塔。

两种表现可以并存、强弱也可以变化，不强迫每个交易日只选一个标签。一次逆市上涨或较低的相关程度也不能单独证明存在可持续的阿尔法收益；如需统计估计，另行说明大盘基准、窗口、模型和不确定性，本轮不预设参数。2026-10-29的统计标签属于旧阅读研究，不再生成对应买卖建议；历史定义见 [清理前术语](../../docs/archive/README.md)。

## 当前小盘轮换用语

| 用语 | 当前含义 |
|---|---|
| 当前策略 | 小盘轮换v0.3，规则只以 [[交易思想/小盘轮换策略]] 为准 |
| 名单与备选 | 五只名单、三只备选；买不满留现金，不无限向后补选 |
| 换手日 | 从固定日历锚点每20个交易日定名单，下一交易日开盘换股 |
| 止盈 | 收盘相对原始买价上涨至少10%后，下一可卖交易日开盘卖，资金留到下次换手 |
| 账户底线 | 现金加持仓相对初始本金的净值跌破0.7后，次日开盘起卖出停用；不等于能保证亏损不超过30% |
| 万一免五 | 每笔佣金为成交额0.01%，无最低收费；过户费与卖出印花税另计 |
| 当前回测窗口 | 2025-02-28至2026-10-29；旧窗口只作历史 |
| 前推记录 | 规则写定后，用之后的数据逐次记录名单、实际成交或条件模拟，再与同日参照比较；不默认第五日退出 |
| 单期模拟 | 日报每期重新以1万元计算，未承接旧仓、现金和原买价；不是连续账户或真实成交 |
| 连续账户模拟 | 连续持仓、现金和原买价的独立模拟；目前仍有备选范围和底线卖出流程差异，不能称完全复现实盘 |
| 等权参照 | 按模型等额配置的比较线；需披露成本与起点，不能称一万元整手账户收益 |
| 淘汰赛观察 | 历史板块解释，缺完整可执行历史；不接入小盘买卖，也不编造收益 |

旧仪表盘的阶段行动、六项买入检查、失效价与五日退出已退出当前日报，其解释只在历史资料中查证。回测数字统一引用 [[交易思想/回测与检验证据]]，写明窗口、模型和费用；不用“回测证明”表达未来确定性。

## 账户与动作

实际持仓、计划、候选、模拟和成交分别表达。旧报告里出现某只股票，不代表今天还持有；没有账户输入不默认空仓。

旧 B1/B2、参与权/确认权和固定仓位档，仅在明确讨论历史时出现，不是当前方案词汇。需要讨论分批或仓位时，按当下实际方案说明，不用旧名称偷带旧规则。

用户可见内容使用交易语言：条件、参与、不参与、买入资格、可做、不做、事实不足、待确认。不要用软件内部流程术语代替判断；引用历史的不当说法时概括为“旧工程口径”，不复述。

## 数字与时间

缺失不写成零，没有概率依据不编概率。真实成交、条件模拟和事后最佳价不能混在同一收益里。不同来源、分母和时段的数字分开说明；后来才知道的信息不冒充当时已知。

新旧版本冲突时，先标明各自日期和身份，不以旧 Wiki 写得更长、被代码引用更多来裁决。
