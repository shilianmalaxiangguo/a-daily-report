# 日报术语契约

这个节点约束日报 skill 的用户可见语言，包括日报前台、执行摘要、诊断输出和运行日志。目标是让结论像交易计划，而不是像工程实现说明。

## 禁用旧术语

新生成的用户可见输出不复述旧工程口径。历史材料如果需要清洗，只在净化函数中处理；wiki、日报前台、摘要、诊断和日志只保留交易语言。

## 术语净化

| 场景 | 推荐说法 |
|------|----------|
| 条件是否满足 | 条件、可做、不做 |
| 是否具备交易资格 | 资格、买入资格、执行资格 |
| 是否参与 | 参与、不参与 |
| 仓位状态 | 0%不参与 / 50%条件执行 / 100%核心进攻 |

## 交易时间窗口

日报、盘中问股、判断账本和复盘列表的用户可见买卖动作只允许落在三段时间：

- `09:30-09:35`：竞价表态、开盘前几分钟承接、强核心前段确认。
- `09:50-10:10`：早盘二次确认、普通结构承接、均线回归和分时修复确认。
- `14:30-14:55`：尾盘例外处理，只用于已观察一整天后的确认、风险收缩或隔夜修复。

缠论和图形分析只提供结构背景，不提供交易时间。买卖动作、狙击手推导、明日唯一动作和推理裁决只按三段交易窗口表达。需要表达普通结构继续观察时，写 `09:50-10:10窗口`。

### 明日新仓与旧仓动作分离

`明日新仓`只回答明天是否新增参与以及比例，不能反推账户当前是否持仓。`明日新仓 0%` 可以与已确认旧仓同时存在，不得把它缩写成“账户已经空仓”。

账户动作固定分开写五项：

- `明日新仓`：只写当前新增档，使用 `0%不参与 / 1x/50%半仓 / 2x/100%满仓`。同股已有 `1x` 且计划总档仍为 `1x` 时，当前新增为 `0`；计划总档为 `2x` 时，当前只新增 `1x=B2`。不同股票的旧仓已占满 `2x` 时，当前新增为 `0`，保留计划对象但等待旧仓释放。
- `旧仓事实`：显式持仓、前日报明日标自动形成的模拟 1x 旧仓、明确外部待核实记录、已确认无旧仓、持仓未输入。
- `旧仓判断`：已经失败、待10:10复核、正常存活、事实不足。
- `旧仓动作`：写清处理窗口与成立条件，不用“不新增参与”代替卖出或持有结论。
- `收盘目标仓位`：写明确比例、按原预案或待确认。

模拟账户把上一份日报的明日标在次交易日默认视为必买完成，直接形成 `1x/50%` 旧仓与 B1，无需等待独立成交确认。这类旧仓进入失败、10:10 复核或正常 T+2 处理。某日报没有新明日标只表示不新增，不自动清除最近未结束的旧仓；只有明确 `当前空仓`、已执行的 `明日空仓` 或退出事实才结束继承。显式持仓与当前空仓输入优先。只有 `external_trade_pending` 等明确外部待核实记录保持实际 `0x`，只核实成交记录，不卖、不新增 B2，也不形成同股 T。持仓未输入时，账户风险暴露和收盘目标仓位都写 `待确认`。

计划生产端只能写 `0/50/100` 三档。实际一手成交落在 `40%-60%` 时可以在账户事实层归入 `1x` 风险带，但计划文字仍写 `1x/50%`，不得出现 `1x/40%` 或 `1x/60%` 计划。

### 空仓词义唯一化

`明日空仓` 是明日账户结果指令，不是 `明日新仓 0%` 的简称。它同时要求：

1. 次日不买任何新股。
2. 集合竞价卖清全部可卖旧仓。
3. 成交后账户仓位为 `0`。
4. 当天不做 T。
5. 集合竞价未全部成交时继续尽早卖；未卖清前不能写已经空仓，只能写清仓中或待卖清。

四类说法必须分开：

- `明日空仓`：执行上面的账户归零动作，优先于失败、10:10复核和正常 T+2 的常规旧仓处理时点。
- `明日新仓 0%` 或 `明日标的为空`：只表示不新增参与；已确认旧仓仍按独立旧仓计划处理，不能推出账户归零。
- `当前空仓`：只描述当前账户仓位为 0，不限制下一交易日按日报计划取得新的买入资格。
- `持仓未输入`：账户事实未知，风险暴露和收盘目标都保持待确认，不能写成当前空仓或明日空仓。

### 市场语言研究证据的注意力边界

市场语言研究提出一个低注意力目标：固定主动查看只保留 `T+1 09:30-09:35` 与 `T+2 14:30-14:55`；`09:50-10:10` 只复核 T0 已经允许的 B2，`13:45-14:10` 只作日终/replay 研究。

当前不会自动提醒。未收到明确提示时，B2 不执行；研究证据也不得新增 `13:45-14:10` 人工观察或临时卖出。

这个目标目前只约束 `市场语言翻译（研究证据）`，没有改写上面的正式三段交易时间契约。只有正式动作生成、验收规则和跨日回测一并完成迁移后，才能把它提升为全日报统一口径；在此之前不得宣称整个日报已经只需两段主动查看。

## 写法原则

- 前台结论用 `资格`、`条件`、`可做`。
- 参与动作直接写 `参与` / `不参与`，不用情绪化口号。
- 日报表头用 `买入资格`。
- 日志也遵守同一口径，例如 `最终执行条件`。
- 可以说 `满足条件才可做`。
- 可以说 `仅观察，条件未满足`。

## 可用示例

- `当前无合格标的，明日0%不参与。`
- `趋势链和个股结构同时满足，明日按50%条件执行。`
- `唯一核心标的确认且失效价清楚，明日按100%核心进攻。`
- `主线承接不足，条件未满足，明日不做。`
- `按09:30-09:35竞价表态、开盘前几分钟承接、打板/回封，或09:50-10:10窗口分层参与；不满足预演情境就回到0%。`

## 不可用示例原则

- 不把工程实现词汇搬到前台。
- 不用口号化、情绪化词汇描述下单动作。
- 不用抽象权限词代替具体条件。
