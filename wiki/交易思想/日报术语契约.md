# 日报术语契约

这个节点约束日报 skill 的用户可见语言，包括日报前台、执行摘要、诊断输出和运行日志。目标是让结论像交易计划，而不是像工程状态机。

## 禁用词

以下词可以作为内部字段或历史材料出现，但不得直接出现在新生成的用户可见输出中：

- `门控`
- `闸门`
- `开闸`
- `放行`
- `执行权`
- `执行权限`
- `买入权限`

## 替换口径

| 旧词 | 新词 |
|------|------|
| 门控 / 闸门 | 条件 |
| 开闸 / 放行 | 可做 |
| 执行权 / 执行权限 | 资格 / 执行资格 |
| 买入权限 | 买入资格 |

## 写法原则

- 前台结论用 `资格`、`条件`、`可做`。
- 日报表头用 `买入资格`，不用 `买入权限`。
- 日志也遵守同一口径，例如 `最终执行条件`，不用 `最终执行门控`。
- 可以说 `满足条件才可做`，不要说 `门控打开后放行`。
- 可以说 `仅观察，条件未满足`，不要说 `无执行权候选`。

## 可用示例

- `当前只保留观察资格，10点确认后再评估30%条件试错。`
- `主线承接不足，条件未满足，明日不做。`
- `满足60分钟确认后才有买入资格。`

## 不可用示例

- `最终执行门控：观察。`
- `环境闸门未开，执行权关闭。`
- `开闸放行后再买。`
