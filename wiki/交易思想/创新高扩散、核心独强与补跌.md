## 定位

这个节点解决一个常见误读：指数或核心股还站在高位，不代表市场还在健康生成新趋势。

创新高数量更接近“新趋势的生成率”，指数、板块价格和核心龙头更接近过去共识的存量。当生成率先收缩、资金再向少数核心集中时，核心相对强势可能是最后的流动性集中点，不一定仍是健康领涨。

这个节点只生成市场结构解释、反证和下一窗口任务，不根据一个低值直接生成卖出、新候选、最终对象、仓位、B1/B2 或退出动作。

## 适用场景

- 创新高数量或全 A 占比快速下降，但指数或核心股仍显得强。
- 创新高首次进入个位数，需要区分周期收缩、主线轮动和长期下跌后的衰竭。
- 判断“龙头很强”到底是领导力，还是板块内部已经只剩少数核心承接。
- 日报的《创新高趋势反馈》需要说明结构含义、主要反证和下一交易日复核任务。

## 不适用场景

- 不用一个创新高低值单独判断见顶、市场暴跌或立即卖出。
- 不用全市场创新高数替代板块内部宽度；全市场数据不能单独证明某个板块主导创新高。
- 不把长期下跌末端的极低值直接解释为周期继续收缩；它也可能是卖压衰竭的候选。
- 历史趋势行的来源、筛选口径或分母不一致时，不把跨日百分比变化写成精确统计结论。

## 路由提示

- 适合读取：`创新高`、`趋势生成率`、`极致扩散`、`有效扩散`、`扩散偏冷`、`极低扩散`、`个位数`、`扩散收缩`、`扩散断层`、`核心独强`、`生态转弱`、`核心补跌`、`替代主线`。
- 容易误触发：只问某只股是否创历史新高，或只问某个价格新高的买点时，不由本节点直接得出交易动作。
- 日报位置：《创新高趋势反馈》内的“结构判断 / 风险含义 / 主要反证 / 下一窗口”，不提前到《明日执行结论》之前。

## 核心判断

### 创新高是趋势生成率

- 指数和核心价格可以由少数高权重或高辨识度资产维持，具有存量惯性。
- 创新高数量统计有多少股票正在生成新趋势，对参与广度更敏感。
- 因此会出现“价格还高，新趋势已经停止生成”的背离。

### 风险常从宽度传向核心，再传向指数

常见路径是：

```text
新趋势生成率收缩
-> 板块后排和多数成分先转弱
-> 资金向少数核心集中
-> 核心出现相对强势
-> 核心承接失败并补跌
-> 压力扩展到指数
```

这是风险传导的候选结构，不是每次都会完整发生的必然路径。

### 核心强势的意义取决于生态

- 板块成交占比、上涨宽度、新高群和后排承接同步扩张时，核心强更接近领导力。
- 板块宽度快速收缩、后排掉队、新高群消失时，核心强可能只是最后的流动性集中。
- 核心没坏只能说方向仍可观察，不能替代板块生态，也不能给后排提高买入资格。

## 字段化判断

| 字段 | 回答什么 | 正向 / 风险观察 |
|------|------------|-----------------|
| `当日新高数` | 当天有多少新趋势样本 | 个位数说明生成率极低，但不单独等于风险确认 |
| `全A占比` | 新高数相对市场容量 | 只能在分母和筛选口径稳定时比较 |
| `较前日变化` | 生成率是加速收缩还是修复 | 单日变化只给观察，连续性更重要 |
| `窗口峰值保留率` | 当前还保留多少前期扩散 | 保留率极低时说明周期从广度上明显收缩 |
| `是否首次个位数` | 当前是否突破可见窗口的旧常态 | 窗口必须明确，不写成历史首次 |
| `板块数 / 头部板块占比` | 新高是成群还是碎片化 | 数量少且分散时，说明没有新主线集群接替 |
| `核心-板块背离` | 核心强是领导还是最后集中 | 必须同时有板块价格与宽度证据，不从创新高总数猜测 |
| `修复质量` | 低值后是否真正重新扩散 | 数量回升、板块成群、核心与板块重新同步才算有效修复 |

### 绝对水位五档

| 全A占比 / 数量 | 绝对水位 | 只回答什么 |
|-----------------|----------|------------|
| `>=5%` | 极致扩散 | 新趋势覆盖很广；若同时放量和一致性加速，次日更容易降温 |
| `>=2% 且 <5%` | 有效扩散 | 趋势赚钱效应已有可用宽度，但仍需观察方向能否持续 |
| `>=1% 且 <2%` | 扩散偏冷 | 扩散不足，不能把局部强势理解为全市场健康扩散 |
| `>=0.2% 且 <1%` | 极低扩散 | 新趋势生成率异常低，必须区分继续收缩与低位修复 |
| `<0.2%` 或新高数 `<10只` | 扩散断层 | 绝对水位突破旧常态，优先复核来源、板块成群和核心同步 |

精确边界按 `5% / 2% / 1% / 0.2%` 向上归档：恰好 `5%` 属于极致扩散，恰好 `2%` 属于有效扩散，恰好 `1%` 属于扩散偏冷，恰好 `0.2%` 属于极低扩散。新高数低于10只时优先归为扩散断层，避免分母或四舍五入掩盖个位数异常。

绝对水位不是买卖动作。最终结构解释使用：

```text
绝对水位 × 变化方向 × 板块成群度 × 核心板块同步性 × 来源质量
```

同样是 `0.8%`，从 `2.3%` 下滑到 `0.8%` 更接近扩散收缩；从 `0.4%` 回升到 `0.8%` 则是绝对水位仍低、方向正在修复。不能只看当天落在哪个档位。

## 1.0 判断与样本校准

### 1.0 粗判断

初始直觉是：创新高降到个位数，就应当视为强风险信号。

### 2026-07-13 必须改变的样本

- 已核实：当日创新高 `6只 / 0.12%`，是现有可见近25个交易日窗口内首次进入个位数。
- 已核实：6 只股票分属 6 个板块，没有一个板块形成创新高集群；半导体只有华微电子一只，不能写成“半导体主导创新高”。
- 结构含义：当时不只是旧主线扩散不足，也没有看到新主线成群接替。
- 使用边界：它不是对 7 月 13 日当天首跌的提前预测，而是对后续风险继续向核心和指数传导的结构预警。

### 必须保留的反例

- 长期下跌后出现极低创新高，同时跌速下降、承接改善、板块宽度持续恢复，可能更接近衰竭和修复候选。
- 单日个位数后，若同源数据显示创新高连续回升、新板块开始成群、旧核心与板块重新同步，则前一日低值只是短暂收缩。

### 1.1 校准后判断

个位数是结构预警的重要候选，但只有和下列事实组合时，才更接近周期收缩：

1. 创新高从前期宽扩散快速下降，而不是长期处于低位。
2. 低值不能很快修复，或数量回升但仍没有形成新板块集群。
3. 原主线板块价格、成交占比、后排承接或二波新高群同步转弱。
4. 核心仍相对强势，但所属板块生态继续恶化，出现“核心独强、生态转弱”。
5. 之后核心承接失败或补跌，压力才进一步得到确认。

### 1.2 绝对水位校准

- `5% / 2% / 1% / 0.2%` 作为可解释的经验分界是合理的，但它们只负责描述绝对水位，不负责独立预测涨跌。
- 旧口径把所有 `<2%` 合并为“偏冷”，会掩盖 `1%-2%`、`0.2%-1%` 和 `<0.2%` 的结构差异；也会让恰好 `5%` 在 Python 与 ECharts 中出现不同结论。
- 五档分层后，日报必须把“当前在哪一档”和“正在向上还是向下”分开写，避免把低位修复误判成继续收缩。
- 这些阈值仍是经验校准，不是长期统计分位。后续需要用更长同源历史检验各档位的基准率、误报率和持续时间。

## 日报接入边界

《创新高趋势反馈》按四行呈现：

```text
结构判断：当日生成率、较前日变化、窗口保留率、板块成群或碎片化
风险含义：说明它是结构预警，不是机械卖出条件
主要反证：长期下跌后衰竭，或低值后同源宽度持续修复
下一窗口：检查创新高是否持续回升、是否形成板块集群、核心与板块是否重新同步
```

历史行缺少逐日来源或目标日时，额外写明：跨日速度只作结构观察，不把来源差异写成精确统计。

## 反证与失效

- 创新高数量虽低，但同源数据连续回升，新板块集群和后排承接同步形成，扩散收缩判断降级。
- 核心与所属板块重新同步上行，板块成交占比、宽度和二波新高群同步修复，“核心独强”不再成立。
- 低值出现在长期下跌末端，随后跌速下降、价格停止创新低并出现持续承接，应优先研究衰竭与修复，不继续累加周期收缩故事。
- 不同来源或不同筛选口径产生冲突数值时，先标记无法精确比较，不选一条更符合叙事的数据。
