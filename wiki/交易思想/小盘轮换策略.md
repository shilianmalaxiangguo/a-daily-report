# 小盘轮换策略 v0.3

| 项目 | 内容 |
|---|---|

| 适用账户 | 本金1万元（初始净值1）；佣金万一免五（0.01%，每笔不设5元最低）；能买主板和创业板，买不了科创板 |

| 对应代码 | `scripts/report/small_cap_rotation.py`（独立策略模块，日报自动接入另行完成；`small_cap_plan.v7`；回测 `strategy_backtest.v4`） |

**一句话：** 每20个交易日，在主板和创业板里，买成交额最冷清、最近一季收入和利润都在增长的5只股票；持有期间收盘比买价高10%就在下一个交易日开盘卖，钱留到下一个换手日；其余拿到下一个换手日，再换掉不在新名单里的。

这份文档只写“照着做”需要的规则和依据。为什么现在用这个办法，见 [[交易思想/当前市场结构与打法]]；它和其他办法的比较，见 [[交易思想/盈利模式库]]。

[独立回测对比报告](../../reports/research/small_cap_rotation_v0.3_backtest_compare_2026-10-30.html)以最近20个月为主要观察窗口，比较止盈、不止盈、股票池、指数与旧方案；整手账户模拟单独列示，历史年化不作为未来收益预期。

## 1. 目标与底线（用户定）

- **锚**：创业板指。同一段时间里，年化收益比它高，**并且**最大回撤比它浅，才算跑赢；两条有一条不满足，这个办法就不值得做。至少要跑赢中证全指。
- **原则**：“稳定盈利= 小亏+ 小赚+绝不大亏+偶尔大赚”；“【偶尔大亏】 + 【偶尔大赚】 ≠ 0 ，钱是有损耗的。”
- **底线**：整个账户净值跌破0.7（即亏30%），全部卖出、停下重新检验。看的是整个账户：现金加持仓的总值，对初始本金1万元，跌到7,000元以下才算；不看单只股票跌了多少，单只不设止损。这条底线不随盈利上移，账户涨到1.5万元以后再跌，仍按7,000元算；要不要改成随最高点上移，由用户决定。
- **不定收益目标**：不以“月化10%”这类数字为目标。目标会骗人，为了追它，人会去加杠杆、押更少的股票。定的是底线（0.7）、尺子（创业板指）和过程（规则、记账、复核），收益是做对过程之后的结果。
- **不做**：不上杠杆，不补仓，不用指数基金顶替选股。

## 2. 选股规则

在换手日收盘后，按下面的顺序排出名单。只用换手日当天或以前已经知道的数据。

1. **股票范围**：沪深A股，剔除当天是ST的，剔除上市不满120天的。
2. **冷门**：算每只股票近20个交易日的日均成交额，取全部合格股票里最小的五分之一（这一步按全部板块算）。
3. **业绩**：只留最近一季单季收入同比、单季利润同比都大于0的。“最近一季”是换手日当天或以前已经公告、而且公告日在报告期结束之后的最新一期。
4. **板块**：只留主板和创业板的，跳过科创板（688、689开头）。按全部板块排时被跳过的科创板股票，日报会注明。
5. **排序**：按近20日日均成交额从小到大，前5只是**名单**，接下来3只是**备选**。

规则不看行业、题材、涨跌和龙头地位。名单落在哪些行业，是结果，不是条件。

## 3. 时间表

| 事项 | 规则 |

| 换手日 | 从2024-07-01起，按交易所日历每数满20个交易日一天 |
| 定名单 | 换手日收盘后，日报给出新名单 |
| 换股 | 换手日之后的下一个交易日开盘 |
| 持有 | 到下一个换手日，约4周；中途不换股 |
| 名单 | 一期里第一次发布的名单锁定到这一期结束；每天的日报显示的都是同一份 |
| 中途才开始 | 第一次买的，用最近一个交易日收盘重新排的名单，下一个交易日开盘买，拿到下一个换股日，再按正常节奏换；已经在拿的不跟着换 |

最近的日子：2026-10-23（周五）定名单、10-26（周一）换股；2026-11-20（周五）定名单、11-23（周一）换股；以后每20个交易日一次，日报会写出下一个换手日和换股日。

## 4. 怎么买

1. 用来做这个计划的钱分成5份。
2. 按名单顺序买，名单买不全就接着用备选。每一只用“现在的现金 ÷ 还空着的名额”这么多钱。
3. 只买整手（100股）。一手的钱超过这一份，就跳过这只，用下一只补。
4. 开盘涨停或停牌买不到的，也跳过，用下一只补。
5. 已经拿着、而且还在新名单里的，不动，也不补到等额。

回测按开盘价成交来算。实际在集合竞价时怎样挂单（挂什么价），没有检验。

**例子（本期，1万元，按2026-10-26开盘价）：** 每份约2,000元。福然德9.78元买2手（1,956元）；天新药业一手2,452元，超过分到的2,011元，跳过；申通地铁7.33元买2手（1,466元）；长久物流5.69元买3手（1,707元）；钱江水利7.72元买3手（2,316元）；备选绿城水务4.39元补上，买5手（2,195元）；剩现金约359元。

**中途才开始的**：用最近一个交易日收盘重新排的名单，买法同上。比如2026-11-02（周一）才第一次买，用10-30收盘排的名单：福然德、新巨丰、申通地铁、东方环宇、钱江水利（备选健尔康、蓝宇股份、长久物流）；按10-30收盘价估算，1万元买福然德2手、新巨丰3手、申通地铁2手、东方环宇1手、钱江水利4手，约剩210元，实际以开盘价为准；拿到11-23换股。

本地日报的“按你的1万元本金照做”只是当期固定本金估算，不是真实成交或连续账户账本。正确账本应承接上期现金、旧仓和原始买入成本。本次远端交付尚未包含日报自动接入。

## 5. 什么时候卖

> v0.3止盈规则已采纳。下方止盈比较中的历史数字描述特定回测路径，不是未来收益预期；口径、窗口与选择偏差见回测证据页。

- **换股时**：换手日之后的下一个交易日开盘，卖出不在新名单里的。开盘跌停或停牌卖不出，顺延到能卖的那天开盘。
- **止盈（v0.3，用户 2026-10-31 采纳）**：持有的股票收盘比买价高10%（含分红送转），下一个交易日开盘卖；开盘跌停或停牌卖不出，顺延到能卖的那天开盘。卖出的钱留到下一个换手日，这一期不再买回这只，也不马上补别的。近期账户对照及限制见独立回测报告；新增数据的前推结果按 H17 检验。
- **高开兑现（v0.3 起在本策略里不用）**：本策略采用止盈10%，不叠加高开兑现。
- **底线**：整个账户净值收盘跌破0.7，从下一个交易日开盘起全部卖出，停下重新检验。
- **不设个股止损**：现行规则保留账户总净值底线，不设单只价格止损。这不代表下跌必然修复。
- **持有期间被戴帽**：不单独卖，拿到换手日；戴帽的股票进不了新名单，到时换掉，卖出仍受停牌、跌停限制。

## 6. 每期对照与复核

日报的执行计划区列最近6期和进行中的一期，每期放在一起比：

| 比什么 | 看出什么 |
|---|---|
| 名单 减 股票池（同一天全部合格股票等额，约220只） | 运气还是规则。收益主要来自股票池，名单只是从池里抽样 |
| 股票池 减 中证2000 | “冷门且业绩增长”这个条件还灵不灵 |
| 名单 对 创业板指 | 用户的锚 |

- **风格提示**：最近6期里，股票池累计跑输中证2000，日报提示“冷门股的优势可能在消失，或者市场风格在切换”，要在下一个换手日前复核，不急着加钱。
- **停用**：前推满6期（约半年）后，累计收益跑输同期创业板指，或者最大回撤比它深，就停用，退回候选重新检验。整个账户净值跌破0.7，随时停下。
- **两本账（H17）**：日报同时记“按止盈10%”和“不止盈”两种结果，名单、按1万元照做和回测曲线都有。前推满6期对一次：止盈的累计收益落后不止盈，或最大回撤更深，就退回不止盈，并在这里记一版。
- **截至2026-10-30**：最近6期，股票池有3期跑赢中证2000，6期累计多11.7个百分点；名单比股票池累计多0.9个百分点；没有触发风格提示。

## 7. 当前窗口的依据

当前采用2025-02-28至2026-10-29约20个月的整手账户模拟：止盈10%年化+21.4%、最大回撤-17.7%；不止盈年化+18.9%、最大回撤-18.6%；同期创业板指年化+9.7%、最大回撤-42.4%。账户模拟从1万元现金开始，保留现金与持仓；连续策略的等权曲线截取到2026-10-29，在独立报告中另列，不能混用。

这些数字只说明该窗口内的表现，不是未来收益预期。账户模拟在完整排序里找可买股票，没有使用日报的固定3只备选上限，也没有实现0.7底线卖出流程；本次两条账户路径均未触及0.7，因此不能据此声称已验证底线执行。

更早的策略形成过程保存在 [[交易思想/回测与检验证据]] 的历史档案中；不再用旧版本的按月收益或旧窗口年化评价当前主策略。

## 8. 风险与还没回答的问题

- **观察窗口限定为最近20个月**；结论仅适用于已观察区间，之后按新增交易日复核。
- **急跌与无法成交**：跳空、跌停或停牌可能使账户净值越过0.7；底线是行动条件，不是亏损保证。
- **热门主线大涨时会落后**：2026年4至6月AI行情里，股票池落后中证2000。
- **有挑选偏差**：“业绩为正”这一条是看过第四轮结果后加的；5只是在用户的账户上比较几种只数后选的。要靠之后的前推记账检验（待检验问题H15）。
- **账户放大以后**：本金到3万元以上，再检验10只；冷门股成交额小，资金大了冲击成本高。
- **数据口径**：退市股按退市前最后价格算，偏乐观；红利税没有计；有10只现在戴帽的股票，在改名记录里查不到戴帽日期。核对过，它们没有进过本策略任何一期名单和备选（主板和创业板的前8名），不影响本策略的回测。
- **没写的规则**：集合竞价怎样挂单。

- **首屏右侧**：执行计划卡，显示持有第几天、名单、下次定名单的日子，以及底线0.7。
- **执行计划区**：
  - 名单与备选表：板块、成交额、业绩、一手多少钱；
  - 按1万元本金照做：买几手、止盈价（买价×1.1）、今天收盘、买入以来涨跌和状态；今天收盘到止盈线的，提示下一个交易日开盘卖；
  - 对照记账表与风格提示；
  - 规则说明。
- **回测区**：执行计划（止盈10%）、执行计划不止盈（对照）、股票池、中证2000、创业板指的净值曲线和分年度收益。
