## 核心认识

市场确实像一种语言，但一条分时曲线只是它发出的声音，不是说话者的身份证。

用户看到的鸭蛋弧、根号弧、顺滑下跌、瞬时爆量、冲高回落和反弹失败，都是价格与成交形成的表象。真正需要翻译的是：

1. 哪个方向的资金正在形成合力。
2. 合力发生在一只个股、一个板块、多个板块，还是全市场。
3. 合力处于启动、扩散、拥挤、衰减、踩踏、修复中的哪一段。
4. 哪些事实支持这句话，哪些事实正在反驳它。
5. 到下一个固定交易窗口时，应该验证什么，而不是盘中临时编一个动作。

因此，市场语言不是“看到一个图形就给它命名”。它是一套翻译顺序：

```text
价格与成交的字母
  -> 反复出现的词组
  -> 资金合力的句子
  -> 范围、方向与阶段的语义
  -> 下一固定窗口的验证任务
```

## 一、市场语言的五层结构

### 1. 字母：最小可观察事实

- 每分钟或每五分钟收益、振幅和收盘位置。
- 成交额、换手、成交额相对同分钟历史基线。
- 个股是否站在 VWAP、昨收、关键均线或成交密集区上方。
- 上涨/下跌家数、板块宽度、核心与后排相对强弱。
- 板块成交占比、竞争方向是否掉队。
- 反弹幅度、反弹持续时间、是否继续创新低。

单个字母不能表达完整意思。一次放量、一根反弹、一分钟跌速扩大都只能触发观察。

### 2. 词组：重复出现的局部关系

- `主动启动`：相对强度先抬升，成交参与增加，核心先于板块表态。
- `扩散承接`：成分参与增多，核心分歧后能稳住，后排不是纯被动跟随。
- `反弹失败`：短线回抽后仍收不回参考线，反弹高点继续下降。
- `压力换挡`：变化点前后跌速明显改变，而不是一条直线慢慢走。
- `第二轮压力`：第一轮已经降温，随后再次出现新的下跌加速。
- `持续修复`：停止创新低、单位成交冲击下降，并出现连续承接。

日报最有价值的不是识别一个漂亮名词，而是保留这些词组出现、确认和失效的时间。

### 3. 句子：资金合力的完整表达

例如：

> 存储板块买方合力从核心启动向板块扩散，成交占比与宽度同向提高；但后排推动效率开始下降，下一窗口重点检查核心回踩承接。

或：

> 上证市值加权指数出现持续卖压，但全市场宽度没有同步恶化；当前更像权重方向压力，暂不能写成全市场踩踏。

一句完整的市场语言至少包含 `方向 + 范围 + 阶段 + 证据 + 反证`。缺一项时，结论就要降级。

### 4. 语义：这句话最多允许解释到哪里

| 已知证据 | 最多允许翻译到 |
|----------|----------------|
| 只有弧形或根号外观 | 价格呈持续加速或非线性外形 |
| 跌速扩大、反弹失败 | 卖方压力发生换挡 |
| 板块成分同步、宽度收缩、单位成交冲击提高 | 卖方合力范围扩大，与反馈放大相容 |
| 第一轮降温后不修复，随后第二轮压力 | 快流向慢流交接风险提高 |
| 逐笔主动订单、撤单、盘口深度也同向 | 才能进一步研究程序化级联机制 |

任何一层都不能单独翻译成“卖方全是量化”或“量化成交占比已经测得”。

### 5. 行动：只服务前一晚计划与预定复核

市场语言研究不能替代前一晚已经决定的动作。它最多回答：

- 预定后台复核应该核对什么。
- 哪个反证出现后应取消原假说。
- 当前证据支持或反对哪一条原假说。
- `09:50-10:10` 预定 B2 是否满足提示条件。

它不允许把窗口外的新发现包装成盘中临时下单理由，也不允许为了收集研究证据增加人工盯盘时间。

## 二、为什么上证更容易呈现“鸭蛋”

上证指数是大量成分股的市值加权聚合。个股里的跳动、短暂反弹和噪音会部分抵消，剩下的共同因子更平滑，所以它比单股更容易形成连续弧线。

但“更平滑”不等于“更能代表每一只股票”。需要同时比较三层：

| 层级 | 回答的问题 | 常见误读 |
|------|------------|----------|
| 市值加权指数 | 大权重合力往哪里走 | 把少数权重的动作写成全市场 |
| 全市场宽度/中位数 | 多数股票是否同向 | 只看指数点位，不看赚钱效应 |
| 板块成分同步 | 压力或买盘集中在哪条线 | 把单股极端行为升级为板块结论 |

只有指数、宽度和多板块同步同向，才允许把合力范围提高到全市场。板块层必须有可追溯的同步百分比；只有 `pressure_direction` 文字不能充当多板块证据。当前 `cross_sector_sync_pct >= 50%` 只表示过半板块同向的语义下限，不是从三个极端案例反推的买入阈值。若上证下跌而中位数和上涨家数稳定，更可能是权重方向压力；若指数稳定但多数个股下跌，则是指数掩盖了真实弱势。

## 三、资金合力的七个阶段

### 1. 启动

向上启动的最低特征：核心或板块相对强度先抬升，成交参与增加，回踩没有立刻失效。

向下启动的最低特征：价格压力首次持续为负，宽度或板块同步开始恶化，短暂反弹不能立即解除候选。

不能只看：第一根阳线、瞬时大单、开盘冲高或单一权重拉升。

### 2. 扩散

向上扩散的最低特征：上涨参与成分增多，板块宽度和成交占比同步扩张，核心分歧后仍有承接，竞争方向开始掉队。

向下扩散的最低特征：下跌参与成分增多，板块或多板块同步转弱，反弹失败从核心扩展到后排。

它是“搭顺风车”最希望看到的阶段，但真正买入仍需原有对象、账户、亏损边界和固定窗口条件。

### 3. 拥挤

本节点中的拥挤专指向上行情的高位拥挤：成交高度集中，后排补涨增多，单位成交推动效率下降，核心继续上涨但越来越依赖更大成交。

拥挤不是立即见顶。它表示同样的价格推进需要更多燃料，继续追涨的赔率开始变差。

### 4. 衰减

衰减必须说明哪一股力量在减弱：

- 向上合力衰减：板块成交占比回落、上涨宽度收缩、后排先掉队，核心跌回 VWAP 或关键参考线后反弹越来越弱。
- 向下压力衰减：跌速下降、单位成交冲击回落，但尚未形成持续承接；它不等于修复。

这比完整鸭蛋弧更早。若目标是提前识别量化退潮，重点不是等曲线长成，而是看扩散停止后核心还能不能修复。

### 5. 踩踏

本节点中的踩踏专指向下反馈加速：跌速扩大、单位成交冲击提高、跨标的同步转弱、第一轮压力后出现不修复长尾或第二轮压力。

踩踏是一种过程描述，不等于所有参与者互相知道对方。不同模型、风险预算和人工执行可能因价格、波动、流动性和参考线连续触发，形成无须协商的反馈链。

### 6. 修复

修复表示此前向下压力后出现向上恢复：价格停止创新低，单位成交冲击下降，反弹能持续，宽度或板块同步重新扩张。

跌速下降本身不是修复。无量、跌停限制、卖盘暂歇或信息重估完成，都可能让曲线暂时变平。

### 7. 不清楚

当指数、宽度、板块和个股互相矛盾，或者分钟事实缺失时，应明确输出“不清楚”。不清楚不是失败，而是防止把故事写在证据前面。

## 四、固定时间钟与事件时间钟

### 低注意力目标：固定主动查看两段，当前不承诺盘中提醒

- `T+1 09:30-09:35`：人工只执行 T0 日报已经决定的 B1（若有）。只有五个完整分钟，适合处理开盘计划，不适合临场识别复杂公式或新增对象。
- `09:45-09:50`：只在日终/replay 还原为前哨样本，不要求人工查看。
- `09:50-10:10`：预定规则是只后台复核 T0 已经允许的 B2；目前不会自动提醒，未收到明确提示时 B2 不执行。
- `13:45-14:10`：只在日终/replay 提取研究样本，不提示、不产生临时动作。
- `T+2 14:30-14:55`：人工按 T0 退出计划处理可卖仓位，不把盘中涨跌重新解释成新的交易计划。

低注意力目标把固定主动查看压缩到 `T+1 09:30-09:35` 与 `T+2 14:30-14:55` 两段；以后若收到真实 B2 提示，只响应提示，不守着分时。盘中信息本身仍有研究价值，但对当前账户而言，未收到明确提示的波动都是不可操作噪音。本节点只约束市场语言研究证据；当前日报其他动作段仍沿用原三段时间写法，尚未完成全系统迁移。

### 事件时间钟：日终/replay 按分钟顺序还原

全天记录：

```text
首次候选 -> 重叠斜率连续 -> 价格同向延续 -> 候选失效 -> 再次候选 -> 阶段切换
```

它允许还原 `10:10-11:00`、`13:00-14:30` 出现的新证据，但目前只在完整目标日事实到齐后计算。窗口外不新增买卖动作，也不要求人工响应；证据只进入收盘复盘、replay 或下一份日报。

### 日终午后样本：为什么保留数据但不增加盯盘

`13:45-14:10` 目前只作日终/replay 研究区间，不是第四段人工窗口，也没有盘中自动提醒。三个锚定案例只能说明三例的向下分钟事件在 `13:45` 已经可见，不能反推出 `14:10` 是更好的结束点。它的价值是给收盘研究留下连续样本，而不是让人提前二十五分钟打开分时图。

用户的生活经验可以改写成一个可检验假说：如果一只股票到 `14:30` 已经处于强势大涨，通常在 `13:45-14:10` 会更早留下向上斜率、VWAP 上方驻留、板块同步和成交参与的足迹。日终/replay 可以保存这些足迹并比较尾盘结果；当前不能据此盘中催促卖出。

这不能写成“`14:30` 后突然大涨的概率极低”的事实。当前没有全市场统计；尾盘突袭涨停、消息驱动的快速重估和先弱后强的快速修复都是真实反例。三个锚定案例只复算向下分钟事件，没有历史强势尾盘样本验证这条向上假说。以后应直接统计“前面没有向上足迹、`14:30` 后却明显拉升”的基准率，而不是用三例直觉代替概率。

后台分类按以下顺序进行：

1. **方向**：五分钟与十五分钟斜率向上、向下还是冲突；价格在 VWAP 或关键参考线上方还是下方。
2. **连续性**：是否只有一根急涨急跌，还是出现重叠斜率连续和候选后价格同向延续。
3. **市场范围**：证据必须与识别出的合力范围相配。全市场范围要看指数、全市场宽度和多板块同步；板块范围要看板块内部扩散；单股独立风险只进入原有个股退出条件，不能冒充市场合力。
4. **恢复力**：反抽能否收回 VWAP 或关键参考线；候选是否快速失效；第一轮压力后是否出现第二轮。
5. **用途边界**：结果只进入研究样本，不改变前一晚计划、认错线、亏损边界和原有退出条件。

午后样本分成三支：

| 后台事实 | 研究分类 | 盘中处理 |
|----------|----------|----------|
| 向下事件已形成斜率连续和价格同向延续，反抽不能修复，事件未失效，并有与合力范围对应的同步证据 | 向下风险样本 | 不提示、不提前卖；留待 T+2 `14:30-14:55` 按 T0 退出计划处理 |
| 中短斜率向上，持续驻留 VWAP 上方，板块宽度与成交参与仍扩散 | 向上趋势样本 | 不提示，不因到达 `13:45-14:10` 产生临时动作 |
| 只有短暂候选、快速修复，或指数、板块、个股证据冲突 | 冲突或失效样本 | 不提示、不抢结论 |

向下风险样本和向上衰减样本不能混为一谈：

- **向下风险样本**看向下事件是否已经成立，用于事后检验压力是否仍在扩散。
- **向上衰减样本**看原本向上的合力是否减弱。价格仍在高位，但板块宽度先收缩、成交推动效率下降、后排掉队、核心跌回 VWAP 后反弹失败，才记录为衰减。
- **持续上涨**本身不是卖出理由。无论记录到哪一类样本，`13:45-14:10` 都不提示、不产生临时动作。

三个锚定案例的午后事件时钟如下：

| 案例 | 候选 | 斜率连续 | 价格同向延续 | 失效 |
|------|------|----------|----------------|------|
| 上证指数 | `13:31` | `13:33` | `13:34` | `13:48` |
| 上证指数再候选 | `13:50` | `13:52` | `13:53` | 持续到收盘 |
| 长电科技 | `13:19` | `13:21` | `13:25` | `13:59` |
| 长电科技假候选 | `14:03` | 未形成 | 未出现 | `14:05` |
| 长电科技再候选 | `14:06` | `14:08` | `14:07` | `14:19` |
| 长电科技尾部再候选 | `14:30` | `14:32` | `14:31` | 持续到收盘 |
| 兆易创新 | `13:21` | `13:23` | `13:25` | `14:20` |
| 兆易创新再候选 | `14:24` | `14:26` | `14:25` | 持续到收盘 |

从 `13:45` 开始截取日终/replay 区间后，要把“期间曾捕获”和“截止分钟仍有效”分开：

| 截止时刻 | `13:45` 至截止曾捕获 | 截止分钟截面仍有效 |
|----------|--------------------------|----------------------|
| `14:00` | 三例 | 上证指数、兆易创新 |
| `14:05` | 三例 | 上证指数、兆易创新；长电 `14:03` 假候选刚失效 |
| `14:10` | 三例 | 三例 |
| `14:20` | 三例 | 只剩上证指数；长电和兆易此前事件均已失效 |

`13:45` 当下三例都已经具备斜率连续与价格同向延续，因此 `13:45-14:00` 的日终/replay 样本并没有漏掉长电。`14:10` 的 `3/3` 只说明长电在第一轮失效后又出现新一轮，不能证明采样必须延长到 `14:10`。这组结果支持记录事件失效与再候选，不能从三例选出 `14:10`，也不能确定 `13:45` 是全市场最优起点。

所有精确时刻都依赖当前尚未校准的 `0.05 bp/分钟` 研究阈值。阈值变化会移动候选与失效边界；后续要加入普通日和多阈值敏感性，不能把这几个分钟当成稳定统计结论。

后续 replay 至少要比较：候选后 `5/10/20` 分钟收益和 MFE/MAE、研究样本对 T+2 尾盘结果的解释力、候选失效率、消息日与普通日差异，以及单账户真实可成交成本。当前不把它升级为提醒或人工处理时间；若未来要改变这一点，必须另行提出并用样本外结果证明收益足以抵消新增注意力和误操作。

### 三个锚定案例给出的窗口教训

以下时刻全部发生在各案例的 T0 同一天，只能评价 T0 表象何时可见，不能验证 T+1 买入、T+2 卖出或 09:50 后台提示。低注意力安排是独立的执行目标，仍需未来跨日样本与正式动作链迁移验证。

- 兆易创新：`09:47` 候选、`09:49` 出现重叠斜率连续，但没有候选后价格同向延续，`09:54` 失效；`10:00` 重来，`10:01` 出现价格同向延续，`10:02` 重叠斜率连续。说明候选失效和证据质量必须保留，不能只记最后成功的一次。
- 长电科技：`10:02` 候选、`10:04` 重叠斜率连续、`10:05` 价格同向延续；主下降段总体降温，但尾盘又有新一轮加速。说明一天可以有多轮过程。
- 上证指数：到 `10:10` 没有越过噪声带的向下候选；第一轮向下候选是 `10:17`，`10:19` 重叠斜率连续，`10:24` 才有价格同向延续。持续到尾盘的一轮从 `13:50` 开始，`13:52` 重叠斜率连续，`13:53` 出现价格同向延续。说明早盘窗口不能预知所有午后风险。

所以三段 T0 样本的合理角色只是“开盘样本、早盘样本、尾盘样本”，不是 T+1/T+2 交易回测，也不是“三次都能提前识别鸭蛋弧”。方向与阶段也不是任意组合：向上可对应启动、扩散、拥挤、衰减或修复，向下可对应启动、扩散、衰减或踩踏；平衡或证据冲突时写不清楚。

保护路径还补出一个重要边界：单根消息重估后即使价格横住，三根重叠十五分钟斜率仍可能保持负值，于是研究口径会短暂显示斜率连续，随后再失效。它只表示原冲击仍留在滚动窗口里，不表示价格继续同向运行，更不表示已经确认量化踩踏、账户身份或真实触发链。价格同向延续、失效、范围、宽度和恢复力必须一起保留。

## 五、公式在市场语言中的分工

日报不需要每天选一个公式冠军。

| 公式或方法 | 市场语言职责 | 使用位置 |
|------------|--------------|----------|
| 单侧滚动斜率、局部曲率 | 描述此刻速度和速度变化 | 盘中或日终研究字段 |
| 单变化点/连续分段 | 记录压力换挡和多轮过程 | 日报阶段与 replay |
| 有限时刻幂律、根号、椭圆 | 描述持续负曲率和鸭蛋右弧外形 | replay / 极端样本解释 |
| 指数 | 持续加速的对照 | replay |
| Gompertz | 比较单轮压力先增强、后边际衰减的经验外形 | replay |
| 普通对数 | 前快后慢的饱和对照 | replay |
| 临界对数 | 极强后段加速的对照 | replay |
| `q/L` 与恢复力 | 区分卖压、承接和修复机制 | Wiki 解释与代理字段 |
| Hawkes | 有逐笔事件后研究自激 | 当前数据条件下不运行 |

盘中局部曲率代理统一写成：

\[
\kappa_{20}(t)=\frac{s_5(t)-s_5(t-15)}{15}
\]

`s_5(t)` 是截至 `t` 的五交易分钟对数价格斜率，使用六个一分钟收盘点拟合；`kappa_20` 表示最近十五个交易分钟里短斜率的平均变化。正式研究产物和论文生成器复用同一计算，判断使用未舍入值，表格只在显示时舍入。

完整公式、变量和失效条件见[[量化跟踪日报公式工具箱]]与[[异质临界值触发与流动性反馈模型]]。

## 六、如何寻找“低风险参与区”和“高位衰减区”

事前无法知道绝对最低点和绝对最高点。日报能做的是提高进入低风险区、避开高风险区的概率，并在错误时尽快承认。

### 低风险参与区候选

至少同时看：

- 合力从单一核心向板块扩散，而不是只有权重或单股独舞。
- 相对强度、成交占比和宽度同向提高。
- 第一次分歧后没有快速失效，回踩有人承接。
- 当前不是后排补涨和一致加速的拥挤尾端。
- 进入原有固定窗口，账户、对象、认错线和亏损边界都满足。

第一版只把这些事实写入日终/replay 研究字段，不生成、保留或取消 B1/B2。正式 B1/B2 仍完全由原有对象、账户、亏损边界和 T0 计划决定；`09:50-10:10` 的低注意力目标只复核前一晚已经允许的 B2，但目前不会自动提醒，未收到明确提示时 B2 不执行。

### 高位衰减区候选

比完整下跌弧更早的语言通常是：

- 板块成交占比先回落，宽度不再扩散。
- 后排掉队，核心还在高位但单位成交推动效率下降。
- 核心跌回 VWAP 或关键参考线后反弹失败。
- 竞争方向开始取得相对强度。
- 第一轮卖压退去后价格仍不修复，随后出现第二轮压力。

它们不能保证最高点。第一版只把“气压、湿度和云层一起变化”保存为日终/replay 样本，不直接生成提醒、减仓或退出动作。

## 七、日报当前的最小翻译结果

当前日报只呈现最多六条研究信息，不搬公式长文：

```text
合力范围与方向：权重 / 单股 / 单板块 / 多板块 / 全市场 + 向上 / 向下 / 平衡 / 不清楚
当前阶段：启动 / 扩散 / 拥挤 / 衰减 / 踩踏 / 修复 / 不清楚
事件时间：首次候选、重叠斜率连续、价格同向延续、完整失效/再候选序列、最近阶段切换
三层对照：市值加权、全市场宽度、板块同步是否一致
主要反证：最可能推翻当前解释的事实
低注意力边界：固定主动查看何时进行，哪些区间只在日终/replay 研究
```

数据不完整时必须显示缺失，不用曲线拟合补齐板块宽度、盘口深度或卖方身份。

## 八、怎样验证这套翻译是否真的有用

### 当日字段

- 只使用当时已经发生的数据。
- 同时记录候选、确认和失效，不只保存成功样本。
- 记录来源日期、粒度和缺失项。

### 事后验收

- 候选之后 `5/10/20` 分钟走势。
- 低区/高区命中、主要行情完成比例、MFE/MAE。
- T+1 条件参与和 T+2 处理的实际可成交区间。
- 单账户资金重叠、手续费、滑点、涨跌停和一手金额限制。

未来最低、未来最高和未来收益只用于 replay 批改，不回填当日判断。三个锚定案例只负责建立语言，不足以证明普遍胜率、固定阈值或约 `40%` 的量化成交占比。

### 已固定的受控保护路径

| 保护路径 | 当前翻译边界 |
|----------|--------------|
| 普通匀速缓跌 | 可写向下压力扩散，但不能因浮点误差写成向下反馈加速 |
| 单根消息重估后横盘 | 可保留“仅重叠斜率连续”和随后失效；没有价格同向延续时不能提高证据质量 |
| 单股持续卖压、市场宽度向上 | 范围保持单股，并记录聚合方向冲突 |
| 快速下跌后持续修复 | 保留下压事件，当前阶段转为修复 |
| 权重指数下跌、上涨家数占优 | 范围保持市值加权指数，不提高为全市场 |
| 指数、宽度、板块健康同向上行 | 可写全市场向上扩散，不误写拥挤、衰减或修复 |
| 只有五分钟路径 | 保留五分钟粒度，不输出一分钟候选时刻 |

这些路径是受控回归，不是历史命中率。它们先证明翻译器能够克制极端案例外推，不能替代后续普通交易日的样本外验收。

## 当前接入边界

- 已实现独立的 `market_language_translation.v1`，从目标日事实只准备一次，以显式只读参数传入完整版和摘要版。
- 新标题“市场语言翻译（研究证据）”只在原有明日执行结论之后展示，并在 Bear HTML 中归为证据区。
- 完整版和摘要版的 `selection_workflow`、`final_target_resolution`、明日执行对象、仓位、执行性质、B1/B2 和退出动作已做接入前后逐字段对比；原研究产物的 canonical JSON 哈希在两次渲染后保持不变。
- 一分钟方向与短长斜率比较使用 `0.05 bp/交易分钟` 噪声带；事件同时保存 `confirmation_basis`、`confirmation_quality` 和 `directional_follow_through_at`。已出现重叠斜率连续后最多容忍两分钟中性区，第三分钟才失效；相反方向立即失效。
- replay 日终事实逐来源核对 `source_date` 与 `query_date`；`query_date=null` 可以保留未知，非空值必须是合法日期且不得早于来源日。
- T+1/T+2 由显式开市日历定位，并保留 `.SH/.SZ/.BJ` 交易所后缀核对标的；缺少 T+1 行情时不会把 T+2 前移，没有完整日历时保持缺失。
- fresh 的来源投影和最终产物都不携带未来日线、资金重叠或交易日历；未来 `5/10/20` 分钟、MFE/MAE、低高区与 T+1/T+2 只进入 replay 副本。
- 只有完整 240 个 A 股一分钟结束时点才标记事实充分；缺少收盘最后五分钟也会降为事实不完整。
- 当前分钟表象处于平衡或不清楚、但仍有未失效事件时，总方向跟随该活动事件；日终投票只作为冲突证据，不能把反向事件时刻拼到另一方向标题下。
- PostgreSQL 使用专属 `source_policy=postgresql.market_language_translation.v1` 精确读写；本地 fresh 与 replay 路径分离。
- 命令入口、AgentRunner 和独立 replay 在报告保存后都会重新读取磁盘完整版，确认与已检查正文一致后才保存研究产物；损坏或错写的报告不能留下看似成功的研究副本。
- 仍不加入默认 LLM Wiki 上下文，不新增数据源，也不让市场语言阶段自动生成候选、仓位、B1/B2 或退出动作。

## 待核实

- 在真实普通交易日而非受控路径中，重叠斜率连续、价格同向延续与候选失效能否稳定早于完整弧形。
- 市值加权、等权宽度和板块同步三层对照怎样在现有数据中稳定取得。
- 单位成交价格冲击代理对不同价格、波动和流动性标的怎样标准化。
- T+1 参与与 T+2 处理是否与压力半衰期匹配，还是需要按阶段而非固定天数处理。
- 哪些市场语言字段只适合收盘复盘，哪些能在不增加人工注意力的前提下改善预定 B2 后台复核。
