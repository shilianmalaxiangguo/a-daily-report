# 当前市场结构与打法

当前唯一主策略是 [[交易思想/小盘轮换策略|小盘轮换 v0.3]]。以最近20个月检验和后续前推为依据，不再用2024年起的研究结论断言今天所有其他方法都失效。

| 身份 | 处置 |
|---|---|
| 小盘轮换 v0.3 | 当前主策略，规则不变；先核对执行与账户，再看结果 |
| 板块资金扩散淘汰赛 | 历史观察材料，未具备公平收益回测条件；不接入选股或择时 |
| 阿尔法六检查、高贝塔、阶段买卖、五日退出与旧建议对账 | 停止当前生成和展示，保留历史结果查证 |
| 指数趋势、其他旧候选、龙头接力及旧个股漏斗 | 撤出当前方法列表，不再并行给建议 |
| 基础行情、财报、指数参照、来源与日期校验 | 小盘与观察需要的数据，不是另一套交易策略 |
| 旧报告、快照、研究代码 | 历史查证，不自动加载为当前规则 |

采用小盘，是用户在已有证据下的选择，不是证明所有其他投资方法永久无效。没有证据的旧方法应停止占用当前执行路径，也不能被写成“已证明亏损”。

费用按**万一免五、无最低收费**。不买指数替代品，不上杠杆，不定月收益目标。收益、回撤、成本与尚未解决的账户差异集中在 [[交易思想/回测与检验证据]]。

做好下一次名单、执行和复核，是当前可控的行动；利润不能由这一理念保证。新想法先记提出日期，用之后的事实检验，不追着旧收益曲线改参数。
