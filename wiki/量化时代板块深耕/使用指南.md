# 板块深耕系统使用指南

## 概述

基于**量化时代的板块深耕**认知,我们开发了三个核心模块来帮助你更好地理解板块运作规律:

1. **板块扩散质量评分系统** - 量化评估板块扩散质量(0-100分)
2. **量化环境识别模块** - 识别当前是否处于量化横行环境
3. **板块成交占比追踪模块** - 追踪TOP5板块的3日/5日成交占比趋势

## 核心认知

### 量化时代的三大变化

1. **从"个股强→板块扩散"变成"板块先铺→筛选核心"**
   - 旧模式: 单票先打出高度,再带出板块效应
   - 新模式: 资金先铺出板块效应,再用二波创新高群筛出真正核心

2. **量化资金必须花小钱办大事**
   - 不能随便"电风扇"拉各个板块
   - 试探2-3天后,扩散质量不足立刻撤离
   - 资金集中在少数板块路径(窄池子进攻)

3. **量化资金有派系,不同板块由不同量化模式定价**
   - 高频交易派: 如中际旭创,日内波动大,成交额稳定在高位
   - 机构+量化混合派: 如中芯国际,需要重大催化,平时成交额较低

## 模块1: 板块扩散质量评分系统

### 评分标准 (总分100分)

| 维度 | 满分 | 说明 |
|------|------|------|
| 核心锚稳定性 | 30分 | 中军是否放量上涨或横住不破 |
| 弹性载体强度 | 25分 | 高弹性标的是否创新高且分时承接好 |
| 后排承接度 | 20分 | 后排涨停数占比 |
| 二波创新高群 | 15分 | 第二波有多少股票继续创新高 |
| 成交占比变化 | 10分 | 板块成交占比是扩张还是收缩 |

### 评级标准

- **强扩散 (70分以上)**: 量化资金仍在,可继续围绕核心寻找参与资格
- **中等扩散 (50-69分)**: 部分指标不足,降低攻击频次
- **弱扩散 (50分以下)**: 量化资金可能离场,先防分化

## 模块2: 量化环境识别模块

### 识别的量化模式

1. **窄池子进攻**
   - 特征: 指数强(+1%以上)但上涨家数弱(<40%)
   - 说明: 资金集中在少数板块路径
   - 动作: 只看被资金持续选择的板块路径

2. **板块先铺**
   - 特征: 多板块同步异动(3个以上),无明显龙头
   - 说明: 资金先买出板块效应,再筛核心
   - 动作: 等二波创新高群,不追第一波后排

3. **量化横行**
   - 特征: 涨停分布分散(5个以上板块),Top20占比<15%
   - 说明: 单一龙头定价权下降,板块节奏优先
   - 动作: 深耕板块运作规律,看资金扩散

4. **单一龙头定价权下降**
   - 特征: 龙头强但板块弱,或板块强但龙头弱
   - 说明: 资金没有围绕核心形成共识
   - 动作: 不把龙头涨停等同于全板块可做

## 模块3: 板块成交占比追踪模块

### 追踪指标

- **3日趋势**: 强化 | 分化 | 持平 | 震荡
- **5日均线**: 用于判断是否明显扩张或收缩
- **趋势序列**: 最近3日的成交占比变化

### 量化离场信号 (三项共振)

1. **信号1**: 板块成交占比回落 (最新值 < 5日均线 * 0.9)
2. **信号2**: 后排掉队
3. **信号3**: 核心跌回VWAP或关键均线

**三项共振时**: 先退出或降级,不等故事证伪

### 使用示例

```python
from domains.market_state.sector_turnover_trend_tracker import build_sector_turnover_trend

# 准备历史数据
history = [
    {"date": "2026-05-20", "turnover_share_pct": 18.0},
    {"date": "2026-05-21", "turnover_share_pct": 17.5},
    {"date": "2026-05-22", "turnover_share_pct": 15.0},
    {"date": "2026-05-25", "turnover_share_pct": 14.5},
    {"date": "2026-05-26", "turnover_share_pct": 13.0},
]

# 构建趋势
trend = build_sector_turnover_trend("AI算力", history)

print(f"最新占比: {trend['latest_share']:.1f}%")
print(f"3日趋势: {trend['trend_3d']}")
print(f"5日均线: {trend['ma5']:.1f}%")
print(f"趋势序列: {trend['formatted_series']}")
print(f"结论: {trend['conclusion']}")
```
