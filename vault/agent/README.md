# Agent Memory

这里记录 AI 协作方式、常见失误、检查习惯和仓库级偏好。

## 适合写入

- 多次出现的协作偏好。
- 容易被 AI 忘掉的工作方式。
- 和 `AGENTS.md` 相比更偏经验、不适合写成强规则的提醒。
- 某次任务后的轻量复盘结论。

## 不适合写入

- 已经必须执行的仓库规则；这类内容应写在 `AGENTS.md`、`SKILL.md` 或 `.trellis/spec/`。
- 交易原则；这类内容应写入 `wiki/`。
- 具体代码实现细节；这类内容应放在代码、测试或规格文档里。

## 条目格式

```markdown
## 标题

- 日期：
- 来源：
- 适用场景：
- 提醒：
- 去向：
```
