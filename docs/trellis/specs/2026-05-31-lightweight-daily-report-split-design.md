# 轻量日报与证据/运行日志拆分设计

日期：2026-05-31
状态：已批准执行第一版

## 背景

当前日报已经完成“先让它存在”的阶段：数据源、市场基底、候选池、执行纪律、replay 和一致性检查都能跑通。但完整版日报约 20 万字符，执行摘要仍约 3 万字符，人的阅读路径过重。

下一阶段目标不是继续往日报里加内容，而是把输出拆成三类文件：

1. 人要读的轻量日报。
2. 复盘要查的证据附录。
3. 系统要看的运行日志。

这符合当前工程策略：先做出来，再把它做好。

## In Scope

- 新增轻量日报输出文件，面向盘前/盘后快速阅读。
- 新增证据附录输出文件，承接原完整版里的长表、候选池、资金、热榜、异动和历史证据。
- 新增运行日志输出文件，承接 preflight、数据源检查、辅助接口体检、保存路径、报告长度和一致性检查结果。
- 轻量日报首屏使用 ASCII 流程图表达狙击手视角，替代长篇纪律表的阅读压力。
- 保留现有完整版和执行摘要，第一版只新增分层产物，不删除旧产物。
- replay 模式与正式模式都应能生成新增产物。

## Out of Scope

- 不重写数据源采集。
- 不重写候选生成。
- 不删除现有完整版日报。
- 不把所有附录内容重新分类到极细粒度。
- 不新增前端 UI。
- 不改交易策略本身。

## Non-goals

- 不追求第一版轻量日报完美排版。
- 不要求一次性把所有旧附录彻底迁移干净。
- 不让运行日志替代数据 preflight 的停止生成能力。
- 不让轻量日报失去 0% 原因、旧仓处理和明日动作。

## Done Definition

第一版完成时必须满足：

- replay 生成后出现四类文件：
  - 现有完整版日报。
  - 现有执行摘要。
  - 新增轻量日报。
  - 新增证据附录。
  - 新增运行日志。
- 轻量日报必须包含：
  - `## 明日账户建议`
  - `## 狙击手执行图`
  - `## 今日市场底色`
  - `## 明日三窗口`
  - `## 最终结论`
- 轻量日报必须包含 ASCII 流程图，并出现 `普通候选`、`强核心`、`已有旧仓`、`失败仓/退潮`。
- 轻量日报必须保留 `0%原因` 或等价的明确不参与原因。
- 证据附录必须包含 `## 证据附录`，并承接完整版里的 `## 八、详细附录` 主体内容。
- 运行日志必须包含：
  - `## 运行日志`
  - `日报关键数据 preflight`
  - `日报一致性检查`
  - 生成文件路径。
- 原有报告一致性检查和现有测试继续通过。

## 输出结构

### 轻量日报

文件命名：

```text
reports/replay/<date>_A股日报_轻量版_replay.md
reports/<date>_A股日报_轻量版.md
```

轻量日报只服务一个问题：明天怎么做。

内容顺序：

1. 标题。
2. 今日基调。
3. 明日账户建议。
4. 狙击手执行图。
5. 今日市场底色。
6. 个股和持仓处理。
7. 明日三窗口。
8. 最终结论。
9. 证据和运行日志路径。

### 证据附录

文件命名：

```text
reports/replay/<date>_A股日报_证据附录_replay.md
reports/<date>_A股日报_证据附录.md
```

证据附录承接完整版里不适合放在第一屏的内容：

- 市场长表。
- 主线成交额趋势。
- 龙虎榜。
- 板块资金。
- 热榜。
- 连板。
- 异动监控。
- 候选池。
- 历史样本和知识复利候选。

第一版允许直接从完整版的 `## 八、详细附录` 开始抽取，后续再细分。

### 运行日志

文件命名：

```text
reports/replay/<date>_A股日报_运行日志_replay.md
reports/<date>_A股日报_运行日志.md
```

运行日志承接系统过程，不进入人读日报：

- preflight 检查。
- 数据源 provider、row_count、失败字段。
- 辅助接口体检摘要。
- 报告保存路径。
- 报告长度。
- 一致性检查结果。

第一版可以从生成时已有的 preflight 数据和保存结果构造，不强求捕获终端所有 stdout。

## ASCII 狙击手执行图

轻量日报使用固定图：

```text
T日收盘候选
    |
    v
先分型
    |
    +-- 普通候选
    |      -> T+1等MA5回踩
    |      -> 09:50-10:10收回MA5/VWAP/0轴
    |      -> 成立50%，不成立不做
    |
    +-- 强核心
    |      -> 优先MA5回踩
    |      -> 健康低开转强可50%
    |      -> 全天强且偏离不大，尾盘最多25%
    |
    +-- 已有旧仓
    |      -> 先处理可卖旧仓
    |      -> 强势周期MA5入/MA7清/MA5T
    |
    +-- 失败仓/退潮
           -> 买点失败仓先处理
           -> 只给一次修复窗口
           -> 不修复就降风险
```

## 第一版抽取规则

轻量日报第一版不要重新生成新判断，只从现有完整版抽取：

- 从标题到 `## 八、详细附录` 之前作为候选正文。
- 保留以下章节：
  - `## 明日账户建议`
  - `## 一、交易纪律` 中的关键信息，压缩为 ASCII 图。
  - `## 二、市场基底` 中的市场状态和少量关键表。
  - `## 五、个股解读`
  - `## 六、明日执行计划`
  - `## 七、最终结论`
- 跳过长表和编号明细。

如果抽取失败，宁可保留原执行摘要作为轻量日报内容，也不能输出空文件。

## 验收样本

以 2026-05-29 replay 为第一验收样本：

- 轻量日报应明显短于完整版。
- 轻量日报能在前 100 行内回答明日是否参与、为什么、先处理什么。
- 证据附录包含原详细附录内容。
- 运行日志包含 preflight 与报告保存信息。
