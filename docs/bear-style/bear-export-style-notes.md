# Bear 导出样式观察

来源：`/Users/chaixixi/Documents/Bear Pro 与实用技巧.html`

## 关键变量

- 正文颜色：`#444444`
- 辅助文字：`#888888`
- 浅边框：`#d9d9d9`
- 浅背景：`#F3F5F7`
- 主题红：`#DD4C4F`
- 正文大小：`15px`
- 正文行高：`1.5 * 1.17`
- 正文字体：`AvenirNext-Regular`
- 标题字体：`AvenirNext-Medium`
- 代码字体：`Menlo-Regular`
- 文档最大宽度：`48em`

## 高亮

- 默认/绿色高亮背景：`#CDF7BD`
- 默认/绿色高亮文字：`#102D05`
- 红色高亮背景：`#FFD5D5`
- 红色高亮文字：`#321A00`
- 黄色高亮背景：`#FCF195`
- 蓝色高亮背景：`#C9E5FF`
- 紫色高亮背景：`#FEDAFF`

## 元素形态

- 链接使用主题红。
- 下划线的线色使用主题红。
- 引用块是左侧细竖线，不是大块背景。
- 表格有细边框、轻圆角、隔行浅灰。
- 代码块浅灰底，小圆角，Menlo 字体。
- 标签是浅灰胶囊。

## 下一步对照点

- 日报模板应优先贴近 `document-wrapper` 的正文宽度与字体节奏。
- 表格可以保留日报密度，但视觉上要接近 Bear 的细边框和隔行灰。
- 语义红/绿应尽量表现为文字高亮，而不是整行整格色块。
