# 创新高趋势反馈设计

## 背景

日报新增一个市场宽度指标：非ST、非新股、非次新股里的阶段新高数量，以及它们反馈到哪些板块。这个模块用于判断资金扩散方向，不生成买点。

## In Scope

- 数据源优先使用 Tushare `stk_factor_pro` 的 `topdays` 字段。
- 默认 `topdays >= 250` 视为阶段新高。
- 用 `stock_basic.industry` 归属板块，用 `stock_basic.list_date` 过滤新股/次新股。
- 用名称和 `stock_risk_map` 过滤 ST、退市风险样本。
- 日报输出新高数量、占全A约5000比例、板块分布、趋势行和Top30明细。

## Out of Scope

- 不接 `snap-ui`。
- 不做事实库/缓存大改。
- 不逐只股票拉250日K线。
- 不把创新高列表变成买入候选池。

## Non-goals

- 不预测明天涨跌。
- 不替代成交额Top50占比。
- 不做复杂主线判定。

## Done Definition

日报 `市场基底` 中出现 `创新高趋势反馈` 小节。它能显示：

- 今日阶段新高数量。
- 占全A约5000比例。
- 近几日趋势行，历史不足时显示 `待累计`。
- 板块分布和代表个股。
- Top30新高个股明细。

## 口径说明

`stk_factor_pro.topdays` 是 Tushare 技术因子口径，表示当前价位处于近多少周期高位。第一版用它避免全市场逐股拉K线。日报文案使用 `阶段新高`，避免把该口径误写成严格的 `收盘价创近250日新高`。
