# 新股炒作周期与市场温度 Wiki 设计

## 背景

2026-05-11 日报已经能识别市场基底偏强、半导体主线、C档观察和无唯一对象，但对两类信息处理不足：

- 新股/次新炒作已经在热榜和新股上市日历中出现，却没有进入前台周期判断。
- 指数放量强阳后，市场宽度、高位股分化和加速透支风险没有形成单独的市场温度判断。

用户提供的两篇盘面文章给出两个可复用视角：

- 新股炒作可分为质地新股、概念新股、纯新股三个阶段。
- 指数强阳不等于市场安全，强阳后要看红绿盘宽度、高位趋势股分化和是否进入加速透支。

## In Scope

- 新增两类 LLM Wiki 知识设计：
  - `wiki/交易思想/新股炒作逻辑.md`
  - `wiki/交易思想/市场周期与强阳风险.md`
- 定义日报可消费字段，而不是长篇理论：
  - 新股炒作阶段。
  - 新股线与主线的关系。
  - 纯新股情绪是否升温。
  - 强阳后的市场宽度。
  - 高位活跃股分化或退潮。
  - 加速透支风险。
- 约束日报表达：新股周期和市场温度只影响观察、仓位和执行资格，不直接生成买点。

## Out of Scope

- 不改选股算法。
- 不接入新的外部数据源。
- 不把文章作者观点原样作为系统真理。
- 不预测牛市顶部或大盘绝对拐点。
- 不把某只新股写成买卖建议。

## Non-goals

- 不建立复杂的新股评分系统。
- 不把新股三阶段机械套到每一天。
- 不把强阳风险写成看空结论。
- 不替代现有主线、资金、唯一对象和仓位等级链路。

## Proposed Wiki Pages

### 新股炒作逻辑

用途：把新股/次新从普通题材中拆出来，作为独立情绪温度计。

核心字段：

| 字段 | 含义 |
|------|------|
| 新股阶段 | 第一阶段质地新股 / 第二阶段概念新股 / 第三阶段纯新股 |
| 代表样本 | 当天和近期最能代表阶段的个股 |
| 板块依赖 | 依赖硬核赛道、热门概念，还是脱离板块独立炒作 |
| 情绪温度 | 冷却 / 启动 / 发酵 / 高潮 / 疯狂 / 退潮 |
| 对主线影响 | 补充风险偏好 / 分流接力资金 / 独立情绪线 |
| 日报动作 | 观察 / 降低追高 / 只看承接 / 风险升温 |

三阶段定义：

- 第一阶段：炒作质地新股。需要硬核赛道、业绩大增或高景气方向，涨临停较少，多走趋势。
- 第二阶段：炒作质地一般但能蹭上市场热门概念的新股，涨临停增多。
- 第三阶段：炒作纯新股。不看质地、不看概念，只因新股身份被资金选择。该阶段代表情绪很纯，也最容易进入疯狂和风险升温。

日报表达样例：

- `新股线处于第二阶段，资金开始从质地新股扩散到概念新股，但尚未进入纯新股普涨。`
- `新股线有向第三阶段扩散迹象，只作为情绪温度计，不直接给买点。`
- `若纯新股普涨后出现跌临停扩散，视为情绪退潮风险升温。`

### 市场周期与强阳风险

用途：避免指数放量强阳后把市场安全感写得过满。

核心字段：

| 字段 | 含义 |
|------|------|
| 指数位置 | 是否突破整数关口或阶段新高 |
| 放量性质 | 健康放量 / 加速放量 / 透支式放量 |
| 市场宽度 | 红绿盘比例、涨跌比是否支持普涨 |
| 高位股反应 | 高位趋势股继续上攻、分化，还是重阴退潮 |
| 调整需求 | 正常震荡 / 需要休息 / 加速逼空风险 |
| 日报动作 | 不追一致加速 / 等分歧承接 / 降低仓位上限 |

判断原则：

- 指数强阳只说明市场基底偏强，不自动说明可执行赚钱效应充足。
- 如果指数新高但红盘家数只是略占优，说明不是普涨狂欢。
- 如果高位活跃股出现一批重阴，次日要继续跟踪是否连续阴线。
- 最健康的上升是慢慢走，该调就调；连续加速阳线可能透支后续空间。

日报表达样例：

- `指数强阳打开观察窗口，但红盘宽度不足以支持普涨结论。`
- `高位活跃股出现分化，明日重点看重阴样本是否继续实体下杀。`
- `强阳后不追一致加速，优先等主线分歧后的承接。`

## Report Integration Design

第一版只进入 LLM Wiki 和 compact context，不改执行代码。

后续如果进入日报前台，可增加一个短块：

```text
### 市场温度补充
| 维度 | 判断 | 对明日动作的影响 |
|------|------|------------------|
| 新股周期 | 第二阶段，向第三阶段观察 | 新股只作情绪温度计，不直接给买点 |
| 强阳风险 | 指数强但宽度未完全普涨 | 不追一致加速，等分歧承接 |
| 高位分化 | 需要跟踪重阴样本 | 若连续阴线，仓位降级 |
```

2026-05-11 推荐前台口径：

`市场基底偏强，但指数新高后的宽度没有充分普涨，高位活跃股出现分化，强阳后不追一致加速。新股线进入第二阶段并有向第三阶段扩散的迹象，长裕/春光/理奇/大普微是情绪温度计，不自动产生买点；若后续出现纯新股普涨和跌临停扩散，要视为市场风险温度上升。`

## Error Handling

- 如果新股数据缺失：写 `新股周期证据不足，仅保留观察`。
- 如果只有单只新股大涨：写 `孤立新股表现，不升级为新股周期`。
- 如果指数强阳但宽度数据缺失：不判断普涨，只写 `宽度证据不足`。
- 如果高位股样本不足：不写退潮，只写 `高位分化待确认`。

## Testing

设计落地时需要增加文档/上下文测试：

- `tests/test_daily_report_skill_docs.py` 检查两页 wiki 被 index 列出。
- `tests/test_llm_wiki_context.py` 检查 compact context 包含：
  - `新股三阶段`
  - `纯新股只作情绪温度计`
  - `强阳后不追一致加速`
  - `高位重阴连续出现才确认退潮`

不要求第一版新增行情计算测试。
