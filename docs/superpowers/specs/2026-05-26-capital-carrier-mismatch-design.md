# 资金载体错配与新题材窗口设计

## 背景

用户给出两条短线经验：一是同一热点里，叙事、核心权重、弹性标的和参与资金可能不是同一种交易周期；二是真新题材要么在早期主动性和第一确认窗口相信，要么后手彻底不追。

这两条经验要进入日报、盘中问股和交易思想 wiki，但不能扩展成新的选股系统，也不能把题材热度替代价格、成交、扩散和承接。

## In Scope

- 在交易 wiki 中沉淀 `资金载体错配`、`核心锚`、`弹性载体`、`新题材窗口` 的判断口径。
- 在实时 tag 池和板块节奏规则中说明：判断细分方向是否真新题材，再决定早信、观察或不追。
- 在 compact LLM wiki context 中投射这些规则，让日报和盘中问股能读取。
- 增加最小测试，保护运行时摘要包含新规则。
- 重新生成 2026-05-25 replay 日报。

## Out of Scope

- 不新增数据库、外部数据源或复杂历史回测。
- 不改变主买、补位、核心观察等动作枚举。
- 不直接给具体股票买卖建议。
- 不改板块涨跌幅数据源或 Tushare/AkShare 回补链路。

## Non-goals

- 不证明任何单一题材必然持续。
- 不把“新题材”写成无条件追高理由。
- 不用核心权重没坏来覆盖后排掉队。
- 不把外盘反馈替代 A 股本地承接。

## Done Definition

- wiki 中可以读到资金载体错配和新题材窗口规则。
- compact LLM wiki context 中可以读到资金载体错配、新题材早信或不信、核心锚与弹性载体口径。
- 相关 unittest 使用 `.generated/venv-py314/bin/python3.14` 通过。
- 2026-05-25 replay 日报重新生成成功。
- 本地代码提交并推送到远端 `develop`。

## 设计

### 资金载体错配

同一热点不能只写成“板块强”。日报和盘中问股需要拆成四个角色：

- `叙事发动机`：今天资金到底在交易什么故事。
- `核心锚`：负责稳住板块和方向可信度的权重或机构定价标的。
- `弹性载体`：负责短线涨幅、换手和情绪扩散的标的。
- `参与资金`：机构、量化、游资、散户合力分别处在什么位置。

当四个角色不在同一种交易周期时，动作不能使用统一持股剧本。核心锚稳定只能说明方向没有立刻失真，不能替代弹性载体承接；弹性载体高潮也不能证明机构核心进入趋势主升。

### 新题材窗口

真新题材的价值在于早期主动性。判断顺序：

1. 是否首次被市场集中讨论，而不是旧主线换壳。
2. 是否有独立核心和同分支扩散。
3. 是否处在走势初期，而不是旧方向中后段再包装。
4. 是否有价格、成交、热榜和承接共同确认。

若满足新题材条件，早期主动性和第一确认窗口可以提高参与质量；错过窗口后，后手不追，等待分歧承接再确认。若不满足新题材条件，只按旧主线内的轮动或题材化脉冲处理。

### 日报与盘中问股落点

日报输出应能回答：

- 当前热点是否存在资金载体错配。
- 核心锚和弹性载体分别是谁，哪个角色先失效。
- 当前细分方向是真新题材，还是旧主线换壳。
- 后手是还能参与，还是只观察、等分歧确认或不追。

盘中问股优先问一句：

`我现在买的是产业趋势、核心锚、量化弹性，还是情绪后排？`

如果答案说不清，只保留观察；如果答案是情绪后排且已经错过早期主动性，不用题材热度提高参与资格。
