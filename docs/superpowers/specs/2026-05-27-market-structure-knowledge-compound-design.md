# 市场结构判断与知识复利设计

## 文档定位

本 spec 定义日报如何从已有市场情绪和氛围判断，升级为可影响明日动作的市场结构判断，并把当天新增判断沉淀为可复用的知识复利提示。

校准样本来自用户提供的复盘文章：创业板指数强势甚至新高，但全市场上涨家数很少，成交额维持高位却主要服务少数方向，消费白酒等对立方向出现反弹，科技老主线仍活跃但短线疲态上升。原有日报若只写情绪冷热，容易漏掉文章里的更高维判断：指数与真实赚钱效应背离、成交额不等于普涨支撑、轮动性质要区分主线延伸和对立反弹、题材荒本身会改变明日节奏。

## In Scope

- 日报前部新增 `市场结构判断` 模块，放在执行摘要之后、明日动作之前。
- `市场结构判断` 必须回答：
  - 指数与真实赚钱效应是否背离。
  - 成交额是普涨支撑，还是少数方向虹吸。
  - 当前轮动是主线延伸、中性新题材，还是对立反弹。
  - 老主线是继续进攻、震荡消耗，还是短线疲态。
  - 当前节奏是积极聚焦、低频聚焦，还是不参与。
- `市场结构判断` 必须影响明日动作、候选数量、主线优先级和是否允许从旧主线里强找机会。
- 日报文末新增 `知识复利提示`，只在当天出现可复用判断时输出。
- `知识复利提示` 必须写清：
  - 今天新增或修正了什么判断。
  - 这个判断来自哪些市场事实。
  - 它建议沉淀到哪个 wiki 节点。
  - 它下次会影响哪个日报字段或动作判断。
- 第一版只产生明确的沉淀建议，不静默改写 wiki。
- 保留已有市场情绪、主线、候选、账户和参与预演逻辑，只新增结构判断层和知识复利回流点。

## Out of Scope

- 不重写整个日报生成链路。
- 不新增大而全的评分系统。
- 不自动修改 wiki 正文。
- 不改账户、仓位、做T、持仓处理等既有规则，除非市场结构判断需要引用它们。
- 不引入新的外部数据源。
- 不改变历史报告文件。
- 不把文章观点照搬成固定结论。

## Non-goals

- 不是让日报更长。
- 不是每天强行生成知识更新。
- 不是用结构判断替代个股价格事实。
- 不是把所有轮动都解释成新主线。
- 不是把指数强势直接翻译成明日可做。
- 不是把成交额高直接翻译成仓位提高。

## Done Definition

第一版实现完成时，必须满足：

- 日报前部出现 `市场结构判断`。
- 类似校准样本能输出清晰结论：指数强但真实赚钱效应弱，成交额高但结构集中，对立反弹不等于主线切换，老主线短线疲态上升，明日节奏偏低频聚焦。
- 明日动作能引用市场结构判断，解释为什么积极、低频或不参与。
- 候选数量和候选分层能受到结构判断影响；题材荒或老主线疲态时，不从旧方向里强行扩散候选。
- 当天有可复用判断时，报告文末输出 `知识复利提示`。
- 当天没有新增判断时，不输出空泛提示。
- 测试覆盖至少一个校准样本：指数强、上涨家数弱、成交额大、轮动分裂、老主线疲态、明日节奏变成低频聚焦。

## 设计思路

现有日报已有情绪与氛围判断，但它更偏向描述温度。新增模块要判断市场结构：指数表现、真实赚钱效应、成交扩散、主线质量、轮动性质和题材新鲜度之间是否一致。

这层判断不直接给股票答案，而是约束后续动作：

- 结构集中时，候选数量收缩。
- 对立反弹时，不把反弹方向直接升为主线。
- 中性新题材出现时，允许进入观察主攻线。
- 老主线疲态上升时，旧方向只保留核心，后排降级。
- 题材荒时，报告优先写低频聚焦或不参与。

知识复利不是另起一个长篇理论段，而是把当天新增结构判断压缩成一条可复用的规则候选。它服务下一次日报，不抢前台动作位置。

## 组件设计

### 市场结构判断构建器

新增一个小而独立的构建器，接收已有市场数据和主线研究结果，输出结构化字典。

建议字段：

| 字段 | 含义 |
|------|------|
| `index_profit_relation` | 指数与真实赚钱效应关系 |
| `turnover_distribution` | 成交额是扩散还是集中 |
| `rotation_nature` | 轮动性质 |
| `old_mainline_fatigue` | 老主线疲态 |
| `new_topic_quality` | 新题材质量 |
| `tomorrow_rhythm` | 明日节奏 |
| `candidate_policy` | 候选处理方式 |
| `summary_text` | 前台摘要句 |
| `action_reason_text` | 明日动作引用句 |

### 前台渲染

日报前台新增 `市场结构判断` 小节，保持短句，不展开成长文。

建议格式：

```text
## 市场结构判断

- 指数与体感：创业板强，但上涨家数弱，指数不能代表真实交易难度。
- 成交结构：成交额高位，但主要服务少数方向，不能按普涨处理。
- 轮动性质：消费白酒更像对立反弹，尚未证明新主线。
- 主线质量：科技老方向仍活跃，但短线疲态上升，只看核心。
- 明日节奏：低频聚焦；没有清晰对象时不参与。
```

### 明日动作衔接

明日动作段引用 `action_reason_text`，避免市场结构判断停留在背景点评。

示例：

```text
明日动作：低频聚焦。原因是指数强但真实赚钱效应弱，成交高位并未扩散，对立反弹还没有证明持续性，旧主线只保留核心观察。
```

### 知识复利提示

报告文末只在产生新判断时输出。

建议格式：

```text
## 知识复利提示

- 新增判断：指数新高不等于真实赚钱效应改善；当上涨家数弱、成交集中、对立方向反弹时，日报应优先进入低频聚焦。
- 事实来源：指数强势、上涨家数偏弱、成交额高位、消费白酒反弹、科技老主线疲态。
- 建议沉淀：`wiki/交易思想/AI摩擦与知识复利.md` 记录来源；正式交易规则沉淀到 `wiki/板块补充/板块中枢与主线延续.md` 或 `wiki/交易思想/价格行为与能量框架.md`。
- 下次影响：市场结构判断、候选数量、主线核心筛选、明日节奏。
```

## 数据流

1. 现有数据源继续生成指数、上涨家数、成交额、板块、主线、候选和市场研究快照。
2. 市场结构判断构建器读取这些已存在字段。
3. 构建器输出结构判断和明日动作引用句。
4. 前台摘要在明日动作前渲染结构判断。
5. 候选和动作逻辑读取结构判断中的节奏与候选处理方式。
6. 报告尾部根据结构判断是否包含新增可复用规则，决定是否输出知识复利提示。

## 异常与降级

- 如果关键市场广度数据缺失，结构判断只能写“关键数据不完整，停止生成”或沿用现有日报数据检查逻辑，不生成模糊结论。
- 如果有指数和成交额但缺少板块轮动细节，只输出指数与成交结构，不判断轮动性质。
- 如果没有新增可复用判断，不输出知识复利提示。
- 如果结构判断与明日动作出现冲突，明日动作必须降级为更谨慎的一侧，并在测试中覆盖。

## 测试策略

- 新增市场结构判断构建器单测。
- 新增前台渲染单测，确保 `市场结构判断` 出现在执行摘要之后、明日动作之前。
- 新增知识复利提示单测，覆盖有新增判断和无新增判断两种情况。
- 新增校准样本单测：
  - 创业板或成长指数强。
  - 上涨家数弱。
  - 成交额高位。
  - 对立方向反弹。
  - 科技老主线短线疲态。
  - 输出节奏为低频聚焦。
- 保留现有日报渲染、前台摘要、wiki 读取测试作为回归保护。

## 实施顺序

1. 新增市场结构判断构建器和单测。
2. 接入前台渲染，新增 `市场结构判断` 小节。
3. 让明日动作引用结构判断中的原因文本。
4. 新增知识复利提示渲染和单测。
5. 补充 wiki 使用说明，明确何时读取和沉淀结构判断。
6. 跑相关测试并生成一份样例报告片段校验阅读效果。
