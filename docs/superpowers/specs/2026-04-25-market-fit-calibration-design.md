# 市场贴合度校准接入日报设计

## 目标

把“趋势是涨出来的 / 眼里要看到市场真正大涨样本 / 大阳线后看承接 / 不做主观臆想”接入现有日报骨架。日报仍按 `市场基底 -> 周期与主线 -> 资金意图 -> 个股解读 -> 明日执行计划 -> 最终结论` 阅读，不新增孤立大章节。

## 页面结构

保持现有一级标题不变：

1. `一、交易纪律`
2. `二、市场基底`
3. `三、周期与主线`
4. `四、资金意图`
5. `五、个股解读`
6. `六、明日执行计划`
7. `七、最终结论`

禁止新增独立顶层章节：`市场贴合度校准`、`大阳线与承接`、`主力画图`。

## 字段落点

### 二、市场基底

在 `### 2. 市场状态结论` 表格增加 `市场贴合度` 行。

| 项目 | 结论 |
|------|------|
| 市场贴合度 | 主线有效，池子偏窄 / 贴合 / 主线偏差 / 数据不足 |

`市场贴合度` 只校准视野，不直接给买入信号。

### 三、周期与主线

继续按日期排列，不改成按板块排列。`周期解读` 和 `主线成交额占比趋势` 的解读字段可吸收强势样本集中度与成交额占比变化。

### 四、资金意图

继续使用龙虎榜资金状态与资金结论。资金意图只表达为：`主线承接`、`轮动试探`、`自救`、`赌预期`、`情绪接力`、`数据不足`。

### 五、个股解读

主线内候选表在原结构内扩展字段：

| 股票 | 代码 | 所属方向 | 标志性大阳线 | 近5日状态 | 承接 | 资金痕迹 | 明日资格 |
|------|------|----------|--------------|-----------|------|----------|----------|

这些字段只用于判断资格，不代表直接买点。大阳线是趋势起点证据，买点仍看承接和 60 分钟确认。

### 六、明日执行计划

多个候选只用于排序，明日动作必须收敛成一个唯一重点对象。

| 明日唯一动作 | 标的 | 条件 | 不满足怎么办 |
|--------------|------|------|--------------|
| 只看唯一对象 | 富瀚微 | 主线确认 + 承接 + 60分钟确认 | 不做 |

没有唯一对象时，必须明确写 `不做`，不能切换到杂毛轮动。

## 用户可见词语

替换旧工程口径，只保留交易口径：

| 旧口径含义 | 新词 |
|------|------|
| 是否满足检查 | 条件 |
| 可以参与 | 可做 |
| 不满足检查 | 不做 |
| 是否具备参与资格 | 资格 |

保留：

- 承接
- 主线确认
- 市场贴合度

内部字段名可以继续保留 `permission_label` 等兼容接口，但渲染层不得直出旧词。

## 验收

- `市场贴合度` 出现在 `二、市场基底 / 市场状态结论`，不新增独立顶层章节。
- `三、周期与主线` 仍按日期排列。
- 候选表体现大阳线、近5日状态、承接、资金痕迹。
- `明日执行计划` 只展示唯一重点对象或明确 `不做`。
- replay 中用户可见口径不出现旧工程口径，并保留 `承接 / 主线确认 / 市场贴合度`。
