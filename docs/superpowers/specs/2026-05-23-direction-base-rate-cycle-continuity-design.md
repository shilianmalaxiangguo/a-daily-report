# Direction Base-rate And Cycle-continuity Design

## Summary

日报的狙击手视角已经能区分“强”和“能不能参与”，但还需要补上一层反代表性偏差：不能只看某个方向或个股像不像好机会，还要看这种机会在当前市场环境里的基础概率、前一日路径和后续验证。

本设计给前台新增一张候选方向证据表，把资金表态、强度扩散、旧方向资金态度、周期连续性缺口和动作结论放在同一处。它的目标是防止“当天像启动”直接替代真实的周期路径，也防止“单日小概率线索”被推成主攻线或唯一对象。

## In Scope

- 定义候选方向证据表的字段、位置和动作落点。
- 定义周期连续性校验：昨日位置、今日位置、允许转移、缺失步骤和资金证据。
- 定义资金换边早期的动作落点：`切换观察，允许预备参与`。
- 定义候选方向表如何约束唯一对象生成。
- 定义方向后验账本的最小字段，用 1/3/5 日方向结果校准基准率。
- 明确规则调整需要累计同类样本，不因单个鲜活案例立刻改规则。

## Out Of Scope

- 不重写完整选股评分、个股扣分、仓位和止损链路。
- 不替代现有 `主线攻击证据` 与 `主线容量与格局判断`。
- 不新增复杂概率模型或综合分。
- 不做 snap-ui 新页面。
- 不在本设计里实现代码。

## Non-goals

- 不预测明天哪个方向一定延续。
- 不把周期理论变成当天相似性的另一个标签。
- 不用单一强票、单一高标、单一消息或单日净流入直接确认主攻线。
- 不让个股形态绕过方向资格生成正式唯一对象。
- 不把一个案例的成功或失败直接推广成新规则。

## Done Definition

- 规格清楚定义候选方向证据表的列、动作落点和升级条件。
- 规格明确周期位置不能从“昨日加速”直接跳到“今日启动”，除非切换证据完整。
- 规格明确 `确认主攻线`、`切换观察，允许预备参与`、`仅观察`、`不参与` 四类动作落点。
- 规格明确方向表对唯一对象的约束：`仅观察` 和 `不参与` 不能生成正式唯一对象。
- 规格明确后验账本按“周期位置 + 方向落点”累计样本，至少 8-12 个同类方向样本后才考虑调整规则。

## Problem

代表性偏差在日报里的表现是：方向或个股看起来很像过去的成功机会，于是被提前写成强结论。典型错误包括：

- 单日高标或异动被推成整条主线。
- 当天最强方向被写成新周期启动，但昨日路径还处在加速、分歧或退潮验证中。
- 旧方向还在分歧修复，新方向只是资金试探，却被写成完整切换。
- 唯一对象看起来很强，但方向层没有完成资金表态、强度扩散和周期连续性校验。
- 复盘只记得命中的狙击，不记录相似失败、误杀和误放。

所以新的判断顺序不是“像不像好机会 -> 给动作”，而是：

1. 当前属于哪个周期路径。
2. 今日资金是否真的投向新方向。
3. 旧方向是否已经撤离或退成背景。
4. 新方向是否有强度扩散或核心承接。
5. 中间是否缺少必要步骤。
6. 动作只能落到匹配的资格层。

## Candidate Direction Evidence Table

前台在摘要或最终结论附近展示一张小表。它不替代完整主线分析，只提供第一眼防偏差约束。

| 候选方向 | 新方向资金表态 | 强度扩散 | 旧方向资金态度 | 周期连续性缺口 | 反证/缺口 | 动作结论 |
|---|---|---|---|---|---|---|

字段含义：

| 字段 | 含义 |
|---|---|
| 候选方向 | 今日被资金或强度线索推到前台的方向 |
| 新方向资金表态 | 主动净流入、成交占比扩张、资金试探、资金分散等 |
| 强度扩散 | 涨停扩散、核心承接、高涨幅集群、普涨、仅高标孤立等 |
| 旧方向资金态度 | `仍有回流`、`分歧修复`、`多数净流出`、`明显退潮` |
| 周期连续性缺口 | 例如昨日加速、今日未完成分歧或退潮确认，不能直接写新周期启动 |
| 反证/缺口 | 缺资金确认、缺强度扩散、旧方向未撤离、仅单日试探等 |
| 动作结论 | `确认主攻线`、`切换观察，允许预备参与`、`仅观察`、`不参与` |

## Action Outcomes

### 确认主攻线

必须同时满足：

- 新方向资金表态清楚。
- 强度扩散成立。
- 周期连续性没有明显缺口。
- 如果属于切换场景，还要看到旧方向多数净流出或明显退潮。

这个落点只确认方向资格，不自动生成个股参与。个股仍需结构、承接、参与窗口和失效条件。

### 切换观察，允许预备参与

适用于资金换边早期：

- 新方向资金表态清楚。
- 旧方向多数净流出或明显退潮。
- 强度扩散或周期连续性仍缺一块。
- 次日只看核心对象是否继续证明。

这个落点可以生成“预备唯一对象”，但不能写成正式唯一对象。预备唯一对象必须等次日竞价表态、开盘承接、回封质量或 60 分钟确认继续证明；条件不满足回到观察。

### 仅观察

适用于单边证据：

- 资金试探但强度不足。
- 强度热闹但资金确认不足。
- 旧方向没有明显撤离。
- 新方向有线索，但不足以构成切换观察或主攻线。

`仅观察` 不是垃圾桶，它表示有线索但还没有动作资格。

### 不参与

适用于没有合格方向：

- 资金表态弱或分散。
- 强度不扩散。
- 旧方向退潮但新方向没有承接。
- 市场没有可做方向。

## Cycle-continuity Check

周期不能只由当天特征命名。每次更新周期位置时，先检查：

| 检查项 | 问题 |
|---|---|
| 昨日位置 | 昨日是启动、推进、加速、分歧承接、退潮，还是背景线 |
| 今日拟写位置 | 今日想写成什么 |
| 是否允许转移 | 昨日位置能否直接到今日位置 |
| 缺失步骤 | 是否缺少分歧、退潮、修复、连续选择等必要过程 |
| 资金证据 | 是否有旧方向撤离和新方向连续资金选择 |
| 前台提示 | 是否需要写明周期连续性缺口 |

明确禁止的写法：

- 昨日加速，今日因为新方向强就直接写新周期启动。
- 旧方向分歧修复中，新方向单日冲高就写完成切换。
- 用当天像启动的形态覆盖前一日路径。

更好的写法：

- `昨日加速后今日出现新方向试攻，但旧周期尚未完成分歧和退潮确认，先按切换观察处理。`
- `旧方向仍是分歧修复，新方向仅资金试探，不能直接写新周期启动。`
- `旧方向多数净流出，新方向连续被资金选择且核心承接，切换确认条件接近完整。`

## Unique-object Constraint

方向表必须约束唯一对象生成：

| 方向动作结论 | 唯一对象规则 |
|---|---|
| 确认主攻线 | 允许在该方向内生成正式唯一对象，但仍需个股条件 |
| 切换观察，允许预备参与 | 只允许生成预备唯一对象 |
| 仅观察 | 只能生成观察对象 |
| 不参与 | 不生成新增参与对象 |

这样避免个股形态绕过方向资格，也避免“最像答案的一只”被误写成可做。

## Direction Review Ledger

方向判断必须进入后验账本，先记录方向结果，再讨论个股收益。

最小字段：

| 字段 | 含义 |
|---|---|
| `sample_date` | 当日报日期 |
| `candidate_direction` | 候选方向 |
| `previous_cycle_position` | 昨日周期位置 |
| `direction_action_outcome` | 当日方向动作落点 |
| `new_direction_fund_vote` | 新方向资金表态 |
| `strength_breadth` | 强度扩散 |
| `old_direction_fund_attitude` | 旧方向资金态度 |
| `cycle_continuity_gap` | 周期连续性缺口 |
| `evidence_gap` | 反证或缺口 |
| `day_1_direction_result` | 1 日后方向是否继续被资金选择 |
| `day_3_direction_result` | 3 日后是否扩散、兑现或转弱 |
| `day_5_direction_result` | 5 日后方向命运 |
| `review_label` | 后验归因 |

后验归因：

| 后验情况 | 归因 |
|---|---|
| 切换观察后未继续被选择 | `切换观察未兑现 / 单日资金试探` |
| 切换观察被误写成确认主攻线 | `判断过早` |
| 仅观察后方向连续被选择并扩散 | `确认偏慢 / 周期切换识别偏慢` |
| 确认主攻线后继续扩散 | `方向确认有效` |
| 不参与后市场仍无方向 | `不参与有效` |
| 不参与后快速走出新方向 | `方向识别偏慢` |

## Base-rate Calibration

规则调整必须看同类样本，而不是一个鲜活案例。

同类样本按“周期位置 + 方向落点”归组，例如：

- `加速后切换观察`
- `退潮中资金试探`
- `推进期确认主攻线`
- `分歧承接中仅观察`

调整条件：

- 至少累计 8-12 个同类方向样本。
- 同时检查成功、失败、误杀、误放。
- 单个案例只记录，不立刻改规则。
- 前台只显示轻量提示，例如 `同类样本仍在累计，暂不改规则` 或 `同类样本显示确认偏慢，后续放宽一档`。

## Integration With Existing Designs

本设计是对以下两份规格的补充，不替代它们：

- `2026-05-15-mainline-attack-evidence-structure-design.md`
- `2026-05-15-mainline-capacity-regime-design.md`

集成顺序：

1. `主线攻击证据` 识别候选方向的资金与强度证据。
2. `主线容量与格局判断` 判断市场能支持几条方向。
3. 本设计新增的候选方向证据表检查旧方向资金态度、周期连续性缺口和动作落点。
4. 只有方向动作落点满足条件，个股层才允许生成正式唯一对象或预备唯一对象。
5. 后验账本记录方向结果，累计同类样本后再讨论规则调整。

## Acceptance Checks

- 前台出现候选方向证据表，且包含 `周期连续性缺口` 和 `动作结论`。
- 昨日加速、今日新方向强时，报告不能直接写新周期启动，除非旧方向撤离、新方向连续被选择且强度扩散或核心承接完整。
- 单边证据只能落到 `仅观察` 或 `切换观察，允许预备参与`，不能直接确认主攻线。
- `切换观察，允许预备参与` 只能生成预备唯一对象。
- `仅观察` 和 `不参与` 不能生成正式唯一对象。
- 后验账本先记录方向结果，再记录个股收益。
- 任何规则调整必须说明同类样本数量、误杀样本、误放样本和保护样本。
