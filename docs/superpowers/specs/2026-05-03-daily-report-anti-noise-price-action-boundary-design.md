# A股日报反噪音与价格行为字段化边界设计

日期：2026-05-03
范围：`a-daily-report` 日报主链、外部推演工具边界、价格行为启发吸收原则
状态：待用户 review

## 1. 背景

MiroFish 这类多智能体推演工具看起来能提供更丰富的市场情景，但它也暴露了一个关键风险：如果日报本身已经包含市场判断、主线判断、个股判断、入场条件，再叠加一层自由推演，很容易变成“玄学 + 玄学”。

日报的目标不是让解释更丰富，而是让交易动作更稳定、更可复盘、更难漂移。

同时，交易经验里确实存在有价值的观察，例如：

- 上涨和下跌的角度；
- 上涨和调整的幅度；
- 震荡后的方向选择；
- 强势段后的承接；
- 加速后的衰竭；
- 板块内群体行为是否扩散。

这些启发不能被简单归为噪音。真正的问题不是“经验能不能进入日报”，而是：**经验必须先翻译成可观察、可计算、可复盘的价格行为字段，不能以自由叙事进入日报主链。**

因此，本 spec 的目标是明确两条边界：

1. 推演型工具不得进入日报主链；
2. 交易经验可以被吸收，但必须字段化、规则化、复盘化。

## 2. 核心结论

MiroFish 或类似工具暂不接入日报系统主链。

它们只能作为研究对象或旁路观察对象存在，不能影响：

- `市场基底`
- `周期与主线`
- `候选池`
- `入场资格`
- `明日唯一动作`
- `reasoning_decision.v1`
- 首页最终结论

日报主链仍遵循：

```text
确定性事实 -> 结构判断 -> 主线判断 -> 候选资格 -> 失败条件 -> 唯一动作
```

但未来可以增强为：

```text
确定性事实 -> 价格行为字段 -> 结构判断 -> 主线判断 -> 候选资格 -> 失败条件 -> 唯一动作
```

不得演变为：

```text
规则判断 -> 情景故事 -> 群体模拟 -> 模型解释 -> 主观信心
```

## 3. 适用范围

本 spec 适用于所有“推演型、叙事型、模拟型、预测型”外部工具，包括但不限于：

- MiroFish；
- 多智能体沙盘；
- 新闻情景推演；
- 事件路径模拟；
- 大模型自由预测；
- 未经过本系统复盘验证的第三方交易判断。

只要工具输出不能稳定转换成字段、条件、失败条件、复盘结果，就不得进入日报主链。

本 spec 也适用于交易经验启发的吸收。任何经验、术语、理论如果不能翻译成价格行为字段，就只能作为研究材料，不能进入日报主输出。

## 4. 非目标

本 spec 不做以下事情：

1. 不实现 MiroFish 接口。
2. 不新增日报章节。
3. 不新增沙盘推演模块。
4. 不让任何模型自由改写日报正文。
5. 不用“别人赚钱案例”作为接入理由。
6. 不把推演结果作为买入、加仓、升级仓位的依据。
7. 不把“能量学”“群体行为”等概念性语言直接写进日报正文。

## 5. 日报主链边界

日报主链只接受四类输入。

### 5.1 事实输入

包括：

- 行情；
- 成交额；
- 涨跌幅；
- 主线占比；
- 候选池；
- 资金痕迹；
- 数据源状态。

### 5.2 价格行为输入

包括：

- 上涨斜率；
- 下跌斜率；
- 上涨幅度；
- 回撤比例；
- 震荡区间；
- 波动收敛；
- 放量突破；
- 突破后承接；
- 加速后衰竭；
- 板块内扩散强度。

这些字段必须来自行情、K 线、成交额、板块扩散或候选池数据，不得来自自由推演结论。

### 5.3 结构输入

包括：

- 中枢；
- 周期；
- 主线切换；
- 承接；
- 60分钟确认；
- 30分钟止损。

### 5.4 受约束的决策输入

只能通过结构化对象进入，例如现有 `reasoning_decision.v1`。

它必须包含：

- 结论；
- 证据字段；
- 触发条件；
- 失败条件；
- 排除对象；
- 信心等级。

自由文本推演、故事化判断、模拟角色意见、情绪化预测，不属于主链输入。

## 6. 概念启发的字段化规则

交易经验可以吸收，但必须先完成字段化翻译。

| 启发概念 | 日报允许使用的字段化表达 |
| --- | --- |
| 能量聚集 | 震荡区间、缩量整理、波动收敛 |
| 能量释放 | 放量突破、脱离区间、连续上行 |
| 群体行为 | 涨跌家数、主线成交占比、板块内扩散 |
| 上涨角度陡 | 上涨斜率强、N日涨幅集中 |
| 调整角度缓 | 回撤斜率弱、回撤比例小 |
| 上涨幅度大 | 主升段空间打开 |
| 调整比例小 | 承接强、筹码未松 |
| 加速后变慢 | 动能衰减、衰竭风险 |
| 运行后休息 | 趋势中继、平台整理 |

日报正文不得写“能量学判断”“能量释放完成”“群体行为共振”这类概念句。

日报正文可以写：

- `上涨斜率强，但回撤比例仍小，承接未坏。`
- `放量突破后没有快速回落，先看是否形成有效承接。`
- `加速后涨幅收窄，明天先防衰竭，不追高。`
- `板块内扩散不足，主线仍是窄池子，候选只观察。`

## 7. 推演工具准入原则

任何推演型工具如果未来要被重新评估，必须先满足以下条件。

### 7.1 不能直接改变动作

不得把 `观察` 升级为 `可做`，不得把 `空仓` 升级为 `试错`。

### 7.2 不能增加信心，只能降低或收紧

推演工具最多只能提示风险、削弱候选、增加失败条件。

### 7.3 不能输出长篇正文

不得进入首页，不得生成解释段落。

### 7.4 必须可复盘

每次输出必须能在次日或后续行情中验证是否有增益。

### 7.5 必须被 schema 管住

如果没有结构化字段，就视为研究材料，不进入日报。

### 7.6 连续观察有效才允许进入下一轮评估

至少经过一段样本期验证，证明它能减少错误动作，而不是增加解释噪音，才允许进入下一轮人工评估。这里的“评估”不等于进入日报主链，也不等于获得动作影响权。

## 8. 允许的旁路形态

如果未来确实要试验 MiroFish，只允许采用“影子模式”。

影子模式要求：

- 不出现在日报首页；
- 不影响 `reasoning_decision.v1`；
- 不改变 `明日唯一动作`；
- 不改变仓位等级；
- 不生成买入理由；
- 只记录：支持、削弱、中性；
- 只记录：它提前提示了什么风险；
- 只记录：事后是否验证。

其中 `支持` 只能表示事后研究标签，不能增加日报信心，不能升级买入资格，不能改变最终动作。

允许的结构类似：

```json
{
  "schema_version": "simulation_shadow.v1",
  "target_date": "2026-05-03",
  "tool": "mirofish",
  "stance": "support | weaken | neutral",
  "risk_hint": "主线承接可能不足",
  "condition_adjustment": "仅作为观察记录，不改变日报条件",
  "affects_action": false,
  "review_required": true
}
```

其中 `affects_action` 必须恒为 `false`。

## 9. 日报反噪音原则

未来日报优化应优先遵循以下方向。

### 9.1 结论先于解释

首页先说能不能做、做谁、不满足怎么办。

### 9.2 字段先于叙事

判断必须落到可命名字段，而不是抽象感觉。

### 9.3 价格行为先于理论语言

允许使用上涨斜率、回撤比例、突破后承接、加速衰竭等字段。

不允许使用能量学、沙盘推演、多智能体共识等概念作为日报结论来源。

### 9.4 反证先于信心

每个候选先写为什么不能买，再看反证是否被消除。

### 9.5 失败条件先于买点想象

买点可以等待，失败条件必须提前写清。

### 9.6 唯一动作优先于多路径推演

日报不负责穷举所有可能，只负责给出明日最该遵守的动作纪律。

### 9.7 复盘优先于预测炫技

没有复盘增益的预测工具，不应进入主输出。

## 10. 用户可见输出约束

日报正文不得出现以下类型内容：

- `多智能体一致认为……`
- `沙盘推演显示……`
- `某情景下可能爆发……`
- `模型认为胜率提高……`
- `综合模拟后建议买入……`
- `虽然规则未满足，但推演偏乐观……`
- `能量释放，所以可以买……`
- `群体行为共振，所以提高仓位……`

允许出现的表达应保持执行化、字段化：

- `不满足条件，不做。`
- `只观察，不给买入资格。`
- `候选被排除，原因是承接不足。`
- `触发条件未出现，明天继续等。`
- `失败条件是跌破30分钟结构位。`
- `上涨斜率强，但回撤比例仍需验证。`
- `放量突破后先看承接，不追高。`
- `加速后出现衰竭风险，明天不主动追。`

## 11. 后续日报可吸收的价格行为字段

本 spec 不要求立即实现字段计算，但允许后续设计围绕以下字段展开。

### 11.1 指数和主线层

- 指数上涨斜率；
- 指数回撤比例；
- 主线成交占比变化；
- 主线内上涨家数扩散；
- 主线放量后是否回落；
- 主线突破后是否缩量承接。

### 11.2 候选股层

- 标志性上涨段；
- 上涨段角度；
- 调整段角度；
- 回撤比例；
- 近5日高低点位置；
- 放量后是否回落；
- 突破后是否守住关键位；
- 60分钟确认是否与日线承接一致。

### 11.3 风险层

- 加速后涨幅收窄；
- 高位放量不涨；
- 突破后快速跌回区间；
- 回撤比例超过前一上涨段的关键阈值；
- 板块内扩散失败，只剩个股孤立强。

这些字段只能服务于候选资格、失败条件、唯一动作，不得绕过原有主线和入场许可体系。

## 12. 验收标准

这个 spec 生效后，后续任何日报优化或外部工具接入方案都必须通过以下检查：

1. 是否改变主链动作？如果改变，拒绝。
2. 是否增加自由叙事？如果增加，拒绝。
3. 是否不能复盘？如果不能，拒绝。
4. 是否把观察升级成买入？如果升级，拒绝。
5. 是否能落到字段、条件、失败条件？如果不能，拒绝。
6. 是否让首页更长、更像作文？如果是，拒绝。
7. 是否直接输出“能量学”“群体行为”等概念句？如果是，拒绝。
8. 是否把交易经验翻译成价格行为字段？如果不是，拒绝。
9. 是否让日报更稳定、更可执行、更容易事后验证？如果不是，拒绝。

## 13. 最终原则

MiroFish 这类工具的正确启发不是“加入更多智能体”，而是提醒日报系统必须更严格地区分：

```text
机会发现 != 入场许可
推演故事 != 执行动作
预测丰富 != 交易有效
模型信心 != 可复盘证据
概念启发 != 日报结论
价格行为字段 = 可吸收经验
```

日报的优化方向不是更会预测，而是更少胡说。

更准确地说：

```text
交易经验 -> 字段化 -> 规则化 -> 复盘化
```

只有完成这个转换，经验才允许进入日报系统。
