# 板块分析增强功能 - 完整规格说明

## 背景

基于近期对市场数据的分析和用户观察，发现当前日报系统在板块关系演化分析上存在以下问题：

1. **成交量陷阱**：成交量大不等于赚钱效应较强，可能是"杀跌放量"
2. **板块内部分析缺失**：缺少中军、弹性载体、后排承接等细分分析
3. **分析时机不当**：在所有阶段都做同样的分析，没有根据市场阶段动态调整

## 核心概念

### 市场容量演化三阶段

基于用户观察，市场容量演化分为三个阶段：

1. **粘合期**
   - 本质：主线不明确
   - 市场特征：市场氛围差，缩量 **或** 杀跌放量
   - 资金行为：资金观望，没有明确方向
   - 对应日报状态："无主线"或"混沌轮动"
   - 超车窗口状态：`observe`

2. **接替期（竞争关系）**
   - 本质：市场成交量只够拉一个板块
   - 市场特征：板块间竞争，今天拉A，明天拉B
   - 资金行为：资金在板块间切换
   - 对应日报状态："双主线竞争"或"主线+背景线"
   - 超车窗口状态：`confirm_next`

3. **分化期（趋势确立）**
   - 本质：某个板块走成趋势，趋势不可逆
   - 市场特征：成交量充足 **且** 做多放量，主线明确
   - 资金行为：资金持续流入主线，应该跟随
   - 对应日报状态："单主线聚焦"
   - 超车窗口状态：`open`

### 成交量质量判断

**关键发现**：成交量大 ≠ 赚钱效应较强

**判断标准**：
- 成交量大 + 涨跌比差（下跌家数多）= **杀跌放量**（赚钱效应不足）
- 成交量大 + 涨跌比好（上涨家数多）= **做多放量**（赚钱效应较强）

**数据验证**（05-26、05-27）：
- 两市成交额：32000亿+（量能充沛）
- 但涨跌比：1354/4082、974/4489（下跌家数偏多）
- 日报解读：**"量能充沛，但赚钱效应不足"**

### 板块内部分析的六个维度

1. **中军识别与跟踪**
   - 规则：成交额>100亿 + 板块内成交占比>15% + 名字辨识度高
   - 输出：中军名称、涨跌幅、量比、状态（放量上涨/横住不破/缩量下跌/放量下杀）

2. **板块内相对位置（龙头/中军/后排）**
   - 规则：
     - 龙头：板块内成交额Top1-2
     - 中军：成交额>100亿 + 板块内占比>15%
     - 后排：其他股票
   - 输出：
     - 龙头/中军/后排的涨幅差
     - 龙头/中军/后排的成交额占比
     - 判断资金是"集中"还是"扩散"

3. **弹性载体识别**
   - 规则：成交额50-150亿 + 波动率高 + 有创新高
   - 输出：弹性载体数量、创新高数量、分时承接状态

4. **后排承接质量**
   - 规则：
     - 后排涨幅分布（是齐涨还是分化）
     - 后排成交额占比
     - 后排收盘位置（守住分时高位 vs 冲高回落）
   - 输出：后排承接质量评级（A/B/C）

5. **二波创新高群**
   - 规则：近5日至少2次创新高
   - 输出：二波创新高股票数量、占板块比例

6. **板块间资金流动**
   - 规则：
     - 板块A成交占比上升 + 板块B成交占比下降
     - 判断是"轮动"还是"扩散"
   - 输出：资金从哪个板块流向哪个板块

## 功能规格

### Feature 1: 成交量质量判断

**目标**：区分"做多放量"和"杀跌放量"，避免成交量放大被误判为赚钱效应较强

**输入**：
- 两市成交额
- 涨跌比（上涨家数 / 下跌家数）

**输出**：
- 成交量质量：`做多放量` / `杀跌放量` / `缩量` / `待累计`
- 成交量质量描述

**判断逻辑**：
```python
if 两市成交额 > 30000亿:
    if 涨跌比 > 0.5:  # 上涨家数 > 下跌家数
        成交量质量 = "做多放量"
        描述 = "成交量充沛且上涨家数占优，赚钱效应较强"
    else:
        成交量质量 = "杀跌放量"
        描述 = "成交量充沛但上涨家数不足，赚钱效应不足"
else:
    成交量质量 = "缩量"
    描述 = "成交量不足，先按缩量处理"
```

**接入位置**：
- 在`market_overview_nodes.py`中增加成交量质量判断
- 在"市场基底"章节中展示

- 成交量质量判断逻辑实现
- 在日报"市场基底"章节中展示成交量质量

### Feature 2: 板块内部分析触发条件

**目标**：根据市场容量演化阶段，动态决定是否需要板块内部分析

**输入**：
- 超车窗口状态（`observe` / `confirm_next` / `open`）
- 主线格局（优先读取 `mainline_pattern`，兼容 `mainline_regime` / `sector_relationship_state`）
- 成交量质量（做多放量/杀跌放量/缩量/待累计）
- 主线持续天数（`mainline_days`，用于区分分化确认期和主线稳定期）

**输出**：
- 是否触发板块内部分析
- 需要分析的维度列表

**触发规则**：

#### 粘合期（observe状态）
- **条件**：
  - 超车窗口状态 = `observe`
  - 或 主线格局 = "无主线" / "混沌轮动" / "混沌接力"
  - 或 成交量质量 = "杀跌放量" / "缩量" / "待累计"
- **触发**：不触发板块内部分析
- **原因**：主线不明确，没有必要分析板块内部

#### 接替期/分化初期（confirm_next状态）
- **条件**：
  - 超车窗口状态 = `confirm_next`
  - 且 主线格局 = "双主线竞争" / "主线+背景线" / "交替竞争"
- **触发**：部分触发
- **分析维度**：
  - 中军识别与跟踪（判断板块延续性）
  - 板块间资金流动（判断竞争关系）

#### 分化确认期（open状态）
- **条件**：
  - 超车窗口状态 = `open`
  - 且 主线格局 = "单主线聚焦"
  - 且 成交量质量 = "做多放量"
- **触发**：完全触发
- **分析维度**：
  - 中军识别与跟踪
  - 板块内相对位置
  - 弹性载体识别
  - 后排承接质量
  - 二波创新高群

#### 主线稳定期（open状态持续）
- **条件**：
  - 超车窗口状态 = `open`
  - 且 主线格局 = "单主线聚焦"
  - 且 成交量质量 = "做多放量"
  - 且 主线持续3天以上
- **触发**：完全触发
- **分析维度**：全部6个维度

**实现位置**：
- 新增文件：`scripts/domains/market_state/sector_analysis_trigger.py`
- 接入位置：在`market_research_snapshot_nodes.py`中调用

**Done Definition**：
- 触发条件判断逻辑实现
- 根据不同阶段返回需要分析的维度列表
- 单元测试覆盖

### Feature 3: 板块内部数据提取

**目标**：实现6个维度的板块内部数据提取

#### 3.1 中军识别与跟踪

**输入**：
- 板块名称
- 板块内所有股票数据（代码、名称、成交额、涨跌幅、量比）
- 板块总成交额

**输出**：
```python
{
    "core_anchor": {
        "code": "603986",
        "name": "兆易创新",
        "volume": 330.18,  # 成交额（亿）
        "volume_ratio_in_sector": 0.18,  # 板块内占比
        "change_pct": 2.21,  # 涨跌幅
        "volume_ratio": 1.1,  # 量比
        "status": "横住不破"  # 放量上涨/横住不破/缩量下跌/放量下杀
    }
}
```

**识别规则**：
1. 成交额 > 100亿
2. 板块内成交占比 > 15%
3. 名字辨识度高（可选，暂时不实现）

**状态判断**：
- 放量上涨：涨跌幅 > 0 且 量比 >= 1.2
- 横住不破：-2% < 涨跌幅 <= 0 且 量比 >= 0.8
- 缩量下跌：涨跌幅 < -2% 且 量比 < 0.8
- 放量下杀：涨跌幅 < -2% 且 量比 >= 1.2

**实现位置**：
- 修改文件：`scripts/domains/market_state/sector_fund_flow_enhancer.py`
- 函数：`_extract_core_anchor`

#### 3.2 板块内相对位置

**输入**：
- 板块名称
- 板块内所有股票数据
- 板块总成交额

**输出**：
```python
{
    "relative_position": {
        "leaders": [  # 龙头（Top1-2）
            {"code": "603986", "name": "兆易创新", "change_pct": 2.21, "volume": 330.18}
        ],
        "core_anchors": [  # 中军
            {"code": "600584", "name": "长电科技", "change_pct": 10.00, "volume": 287.85}
        ],
        "followers": [  # 后排（其他）
            {"code": "...", "name": "...", "change_pct": ..., "volume": ...}
        ],
        "analysis": {
            "leader_avg_change": 2.21,
            "core_anchor_avg_change": 10.00,
            "follower_avg_change": 3.2,
            "leader_volume_ratio": 0.18,
            "core_anchor_volume_ratio": 0.16,
            "follower_volume_ratio": 0.66,
            "conclusion": "资金向核心集中"  # 或 "资金扩散"
        }
    }
}
```

**判断规则**：
- 龙头：板块内成交额Top1-2
- 中军：成交额>100亿 + 板块内占比>15%
- 后排：其他股票

**资金集中/扩散判断**：
- 资金向核心集中：龙头+中军成交占比 > 50% 且 涨幅差 > 5%
- 资金扩散：龙头+中军成交占比 < 40% 且 涨幅差 < 3%

**实现位置**：
- 新增函数：`_extract_relative_position`

#### 3.3 弹性载体识别

**输入**：
- 板块名称
- 板块内所有股票数据
- 新高数据

**输出**：
```python
{
    "elastic_carrier": {
        "count": 3,
        "stocks": [
            {"code": "002185", "name": "华天科技", "change_pct": 10.02, "volume": 112.43, "is_new_high": True}
        ],
        "new_high_count": 2,
        "intraday_support": "强"  # 强/中/弱
    }
}
```

**识别规则**：
- 成交额 50-150亿
- 波动率高（涨跌幅 > 5%）
- 有创新高

**实现位置**：
- 修改函数：`_extract_elastic_carrier`

#### 3.4 后排承接质量

**输入**：
- 板块名称
- 板块内所有股票数据（排除龙头和中军）

**输出**：
```python
{
    "follower_support": {
        "grade": "A",  # A/B/C
        "avg_change": 3.2,
        "gain_5pct_count": 5,
        "gain_3pct_count": 10,
        "volume_ratio": 0.66,
        "description": "后排承接强，涨幅有梯队"
    }
}
```

**评级规则**：
- A级：涨幅>5%的股票>=5只 且 涨幅>3%的股票>=10只 且 后排成交占比>40%
- B级：涨幅>5%的股票>=3只 且 涨幅>3%的股票>=5只
- C级：其他

**实现位置**：
- 新增函数：`_evaluate_follower_support`

**输出**：

```python
        ],
        "description": "32只持续创新高，扩散质量优秀"
    }
}
```

**识别规则**：
- 近5日至少2次创新高

**实现位置**：
- 修改函数：`_count_second_wave_new_highs`

#### 3.6 板块间资金流动

**输入**：
- 所有板块的成交占比数据（今日 vs 昨日）
- 所有板块的涨停数数据（今日 vs 昨日）

**输出**：
```python
{
    "sector_fund_flow": {
        "flows": [
            {
                "from_sector": "电力",
                "to_sector": "半导体",
                "volume_change": 200,  # 估算资金量（亿）
                "type": "轮动切换"  # 轮动切换/扩散分流
            }
        ],
        "description": "资金从电力轮动到半导体"
    }
}
```

**判断规则**：
- 轮动切换：板块A成交占比下降 且 板块B成交占比上升 且 总成交额变化<10%
- 扩散分流：板块A成交占比下降 且 板块B成交占比上升 且 总成交额上升>10%

**实现位置**：

**输入**：

- 主线容量
- 主线格局
- 超车窗口状态
- 板块竞争关系

**输出**：
- Markdown格式的市场容量演化章节

**报告格式**：

```markdown
### 市场容量演化

**当前阶段**：接替期（竞争关系）

**成交量状态**：
- 两市成交额：32643亿（近5日平均：31000亿）
- 成交量质量：杀跌放量（涨跌比：1354/4082）
- 主线容量：单线容量（只够支撑一条主线）

**板块竞争关系**：
- 半导体：13.7%（稳定）

**演化判断**：
- 从"分化期"回到"接替期"

**明日观察**：
- 如果成交量继续缩量 → 进入"粘合期"
- 如果半导体持续拉升 → 确认"分化期"
- 如果电力储能反超 → 继续"接替期"
```
