# 板块数据可信度复核 PRD（2026-10-28）

本 PRD 回应 2026-10-27 板块日报中“免税店”成员中位数接近零后产生的疑问。Goal 是核查来源、原价与指标含义，修复已确认的留存和显示问题；本次不切换来源、不新增指标框架，不把一张看起来完整的图当作数据已经可靠。

## 1. 结论先行

当前怀疑有依据，但不能因此认定所有数据错误。全26只定向后查支持免税店中位数为零；同时查到日照港首尾不复权价差与来源日涨跌存在约1.06个百分点差异，原因定位到参考前收盘价不同于上一日不复权收盘。原始留存不完整、兼容服务身份、最新名单回看和收益口径仍有限制，不能用这项零值获证就宣布整个板块数据集可靠。本次核查不增加新的买卖规则。

## 2. 已核实与未核实

### 已核实

- `snapshots/replay/2026-10-27_replay.json` 中免税店 `885898.TI` 有 26 个唯一成员、6 个日期、156 个唯一代码—日期组合，没有发现重复或把缺失填成零。
- 2026-10-20、21、22、23、26 的 130 条原始 `close/pre_close` 使用 Decimal 独立复算，与保存的 `change_pct` 最大差小于 `1.9e-14` 个百分点。
- 五日收益排序的第 13、14 项接近零，所以 26 只的中位数接近零；去掉最高涨幅后，中间位置仍接近零。
- 官方 Tushare 文档中的 `ths_index`、`ths_daily` 是同花顺板块指数目录和行情接口；“Tushare”和“同花顺板块体系”不是完全互斥的两套分类。
- 10月28日通过同花顺问财按26个明确代码取得10月20、26、27日不复权收盘价，代码、名称和日期字段全部对应。25只首尾收益与保存值在浮点精度内吻合，中间两只武商集团6.99→6.99元、海南机场2.62→2.62元，支持中位数为零。
- 另一只日照港为2.81→2.76元，首尾收益约-1.78%，保存五日收益约-0.72%。问财与兼容服务定向补查的27日 `pre_close` 均为2.78元，而不是26日不复权收盘2.81元；按2.78元计算与原保存涨跌吻合。不能将这两种收益口径混称，也不能直接判上游错价。
- 问财与兼容服务是不同查询通道，尚未证明上游后端独立；后查时间不冒充当时已知。

### 未核实

- 原成员快照没有留存2026-10-27的原价。后来虽补查到26只收盘价与日照港参考前收盘价，仍没有恢复当时完整原始响应；日照港参考价差的除权除息等具体原因缺公告核验。
- 当前配置的服务主机是 Tushare 兼容服务；官方凭证、权限、返回值和兼容服务之间的差异尚未完成对照。
- `membership_basis=latest_at_query` 使用查询日最新成员回看整段窗口；没有逐日历史成员就不能把结果解释成当时真实的扩散宽度。
- 概念指数的权重、成分变更、复权与可成交工具映射尚未与成员等权中位数统一核实。

## 3. 范围

### In Scope

1. 新采集成员比较保留 `close`、`pre_close` 并校验派生涨跌，继续保留交易日、来源、查询日和取得时间；原始响应全量留存不在本次实现范围。
2. 对原始价格与派生涨跌做一致性核对；不一致、缺失或同日冲突时保留缺口并停止把该行当作完整样本。
3. 在核查记录中区分实际兼容服务与同花顺问财，不将Tushare接口名当作官方直连证明。
4. 保留“最新名单回看”的限制，不新增历史成员采集与新展示方式。
5. 将“去掉5日涨幅最高的一只后，其余成员的中间涨幅”作为直白的检查项，不解释为指数贡献或卖出建议；修正近零显示、颜色与下跌误释，不改变选择顺序。
6. 另存补查资料，重新生成选定 replay 阅读页；不改原快照，不覆盖正式历史或数据库。

### Out of Scope / Non-goals

- 不在没有对照证据时切换官方 Tushare、同花顺问财或其他服务。
- 不用当前实时数据倒填 2026-10-27，不把问财补查值覆盖成主来源值。
- 不恢复旧买卖执行层、固定仓位、固定时窗或单一买入对象。
- 不因为本次审计顺手增加评分、排行榜或自动买入结论。
- 不在本次完成官方双源采集、历史逐日成员、新分布图或全部原始响应留存。

## 4. 完成条件

- 新采集保留价格字段，派生涨跌矛盾有测试；一只缺价不丢掉其他成员和成交额，旧快照继续可读且不倒造原价。
- 对免税店零值给出全26只比对证据，同时保留日照港差异、真实后查时间、来源身份和未核实范围。
- 同一代码同一交易日的来源冲突不按先后静默选择；正式历史指纹保持不变。
- “成员收益中间值”与“去掉5日涨幅最高的一只后，其余成员的中间涨幅”不被文案当作单只股票贡献分解；板块整体与个股相对表现可分别查看。
- 近零不显示负零或被误释为下跌，真正损失与缺失仍分别表达。定向测试、原始行独立复算和 PC 页面检查通过；不把这些证据表述成策略已经盈利。

## 5. 执行顺序

1. 先补失败样本：缺 `close/pre_close`、目标日缺一行、同代码同日冲突、最新名单回看的误读。
2. 再改最小保存与校验代码，保留现有正确快照和页面，不改正式历史。
3. 用问财作有界历史补查，记录实际通道、日期与复权口径；不将相同后端重复计数，也不擅自切换服务。
4. 重新生成2026-10-27选定 replay 阅读页；保留源事实与缺口，不用后查值覆盖原快照。
5. 由独立上下文审查风险，主线程按失败反例复测，再检查PC页面与保护文件；不把局部核验说成全部数据可靠。
