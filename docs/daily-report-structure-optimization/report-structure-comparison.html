日报展示结构修改对比

这页只解释本轮展示结构变化：Markdown 先看明日动作，再看证据；Bear HTML 跟随同一顺序。明日对象、仓位、执行性质仍来自原结构化结果。

一屏结论

Markdown 动作前置 ## 明日执行结论、执行条件、不执行条件先出现，板块资金证据后置。
Bear HTML 同序展示 动作段使用 bear-section-action，证据段使用 bear-section-evidence。
不变项 不改明日标的 不改候选池、评分、淘汰、数据源、最终对象解析和决策字段。
验证 576 条相关测试通过 真实 replay 已尝试，当前因路径诊断来源日期缺失停止生成，非本轮展示改动导致。

结构顺序对比

修改前：先证据，后动作

读者会先看到板块资金证据，再往后找最终动作。

1
阅读地图首屏导航。
2
账户日序表 / 日报裁决总览账户和裁决摘要。
3
板块资金扩散淘汰赛板块路径、资金载体、淘汰理由先出现。
4
板块资金载体复核 / T0推演继续读证据和推演。
5
明日执行结论最终动作较晚出现。
6
执行条件 / 不执行条件条件在证据之后。

修改后：先动作，后证据

先确定明天做不做、做什么、什么条件不做，再看证据。

1
阅读地图第一行直接指向明日执行结论和条件。
2
账户日序表 / 日报裁决总览账户位置和前台摘要。
3
明日执行结论明日仓位、执行对象、执行性质先出现。
4
执行条件 / 不执行条件先看什么条件可做，什么条件不做。
5
板块资金扩散淘汰赛解释动作依据，不新增明日对象。
6
板块资金载体复核 / T0推演作为后续证据入口。

怎么读这次变化

这次不是让日报重新选股，而是调整“你先看到什么”。修改后，人工和 AI 都会先拿到明日动作，再进入板块资金、资金载体和 T0 推演证据。证据仍然重要，但它的角色是解释和复盘，不是新增一个明日对象。
