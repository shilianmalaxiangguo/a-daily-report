# 修复日报指数日期错位并增加双源核对

状态：✅ 已完成（待用户确认提交）

## Goal

修复日报把上一交易日指数数据当作目标日数据的问题，并要求六个报告指数在生成前完成目标日期一致性和双源交叉核对，避免错误指数继续传播到整份日报。

## User Story

- **角色**：日报使用者和维护者
- **场景**：生成当日或指定交易日的 A 股日报
- **目标**：报告中的指数点位和涨跌幅确实属于目标交易日，并有第二来源核对证据
- **成功标准**：六个指数全部核对通过后才生成日报；任一指数日期缺失、字段不完整或两来源差异超限时停止生成并列出原因

### 用户旅程

1. 用户运行日报生成命令 -> 系统采集六个指数的目标日日线。
2. 系统使用独立来源读取同一交易日数据 -> 逐项核对日期、收盘和涨跌幅。
3. 六项全部通过 -> 系统保存核对证据并继续生成日报。
4. 任一项不通过 -> 系统停止生成并明确指出指数、来源日期和差异。

## What I Already Know

- `2026-07-13` 日报把上证、深证、创业板、中证500和中证1000的 `2026-07-10` 数据写成了当日数据；中证全指使用了 `2026-07-13` 数据。
- 根因是 `_latest_index_payload()` 只取查询窗口里的最后一根 K 线，没有要求其日期等于目标日期。
- Tushare `index_daily` 与腾讯日 K 均确认 `2026-07-13` 上证收盘为约 `3913.79`，涨跌幅为约 `-2.06%`。
- 日报展示六个指数：上证指数、深证成指、创业板指、中证全指、中证500、中证1000。
- 当前生成前检查只判断指数载荷存在和点位大于零，不核对目标日期，也没有独立来源证据。
- 工作区已有其他未提交修改，本任务只修改与指数采集、核对、生成前检查和对应测试直接相关的文件。

## Requirements

- [x] R1: 六个报告指数的主来源数据必须明确携带 `trade_date`、`close`、`pre_close`、`change_pct` 和来源标识。
- [x] R2: 指数采集函数只接受 `trade_date == target_date` 的目标日日线；查询窗口内只有更早数据时不得按成功返回。
- [x] R3: 使用腾讯日 K 作为独立核对来源，逐项核对六个指数的目标日期、收盘和涨跌幅。
- [x] R4: 核对结果必须保存为结构化事实，包含目标日期、来源、容差、六项明细、差异和失败原因。
- [x] R5: 日报生成前检查必须要求六项全部通过，并确认当前报告载荷仍与核对证据一致；任一项失败时停止生成。
- [x] R6: 修正 PostgreSQL 中 `2026-07-13` 的错误指数事实，并重新生成该日正式日报及相关产物。
- [x] R7: 指数修复不得改变候选生成、最终对象、仓位、执行性质、B1/B2 或退出动作的计算逻辑。

- 核对失败必须在报告渲染和文件写入前暴露。

### 安全

- 不新增凭证，不在日志或核对事实中记录敏感配置。

### 兼容性

- 所有 Python 命令使用 `.generated/venv-py314/bin/python3.14`。
- 保持现有日报命令参数和报告文件命名不变。
- 指数双源核对从报告日期 `2026-07-13` 起强制生效；更早日期仅在已有核对事实时复核，不在本任务批量迁移。
- 历史 replay 只接受目标日期明确的事实，不用当前行情替代历史日期。

## Non-goals

- 不在两来源冲突时静默选择其中一个来源继续生成。

- 不以当前实时行情回补其他历史日期。

## Root Cause

- **现象**：`2026-07-13` 日报把上证 `2026-07-10` 的 `3996.16 / -1.00%` 写成当日数据，且同一错误传播到多个报告段落。
- **根因**：指数载荷构建函数只选择窗口最后一根 K 线；采集成功条件只检查载荷非空或点位大于零；生成前检查不核对目标日期与第二来源。
- **影响范围**：六个指数都可能在供应商数据尚未更新时混入前一交易日事实，并影响市场底色、风险偏好和后续文字判断。

## Reproduction

1. 让目标日查询只返回前一交易日 K 线。
2. 调用 `get_major_indices_from_tushare_first()` 或单指数入口。
3. 预期：目标日事实不足，停止继续生成；实际：前一交易日载荷按成功返回。

## Source Of Truth

- 主来源：Tushare `index_daily` 的目标日原始日线。
- 独立核对来源：腾讯 `fqkline` 日 K 的目标日和前一交易日日线。
- 两来源必须同属目标交易日且数值在明确容差内；冲突时不生成日报。
