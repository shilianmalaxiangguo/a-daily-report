# Research: 入场比较规则冻结

## Question

怎样把“集合竞价直接买 1x”和“B1/B2”变成互不偷换仓位、不会利用未来分钟、可以逐笔重放的比较。

## Findings

### 必须分开的两个问题

1. **同样只买 1x，何时买**：集合竞价一次买入 1x，对照等待价格条件成立后再买 1x。
2. **计划允许 2x 时，第二个 1x 是否值得**：集合竞价直接买完整计划，对照 B1 先到 1x、B2 确认后才到 2x。

正式契约里 B1 已经是 `1x/50%`。Wiki 中“先买 0.5B、剩余 0.5B 等确认”没有给出 B 与 x 的唯一换算，因此只能作为额外的“拆分 1x”实验，不能叫作当前正式 B1/B2。

### 五种执行方式

| ID | 仓位与买点 | 回答的问题 |
|---|---|---|
| `auction_1x` | 开盘价代理一次买 1x | 用户偏好的直接基线 |
| `qualified_b1_1x` | B1 价格条件成立后，下一分钟开盘买 1x；不成立则不参与 | 等确认再买同样 1x 是否改善结果 |
| `split_1x_confirm` | 开盘买 0.5x，进一步确认后下一分钟开盘再买 0.5x | 把同一个 1x 拆两笔是否更好；实验规则 |
| `formal_plan_b1_b2` | 50%计划最多 1x；100%计划先 B1 1x，再由 B2 补到 2x | 当前正式计划的价格行为代理 |
| `auction_full_plan` | 50%计划开盘买 1x；100%计划开盘买 2x | 与正式计划相同最大仓位的直接对照 |

### 当时可知的 B1 价格条件代理

所有判断只读截至当前分钟结束的记录，成交使用下一分钟开盘。

**09:30-09:35 主动进攻路径**：在 09:35 结束后同时满足：

- 09:35 收盘不低于累计 VWAP；
- 09:35 收盘不低于昨收；
- 09:35 收盘不低于开盘；
- 09:35 收盘距前五分钟高点回撤不超过 2%；
- 开盘相对昨收不高于 5%，避免远离认错线后追入。

满足时使用 09:36 开盘代理 B1 成交。

**09:50-10:10 承接修复路径**：从 09:50 起逐分钟检查：

- 连续 3 个已结束分钟收盘不低于各自累计 VWAP；
- 当前收盘不低于当日开盘；
- 当前收盘不低于 T0 前五日收盘均价；
- 当前收盘不低于 3 分钟前收盘；
- 当前价相对昨收不超过 5%。

首次满足时使用下一分钟开盘代理 B1 成交；10:10 结束后不新增。

### B2 / 拆分 1x 第二笔价格条件代理

从 09:50 至 10:10 检查，且必须晚于第一笔：

- 连续 3 个已结束分钟收盘不低于累计 VWAP；
- 当前收盘不低于昨收；
- 当前收盘突破 09:31-09:35 的最高价；
- 最近 5 分钟成交额不低于之前 5 分钟；
- 当前价相对昨收不超过 5%。

首次满足时使用下一分钟开盘成交。没有满足就没有第二笔，不以当日后续上涨倒推确认。

### 开盘位置与早盘路径

开盘缺口按昨收分类：

- 大幅高开：`>= +5%`
- 中高开：`+2% 至 +5%`
- 平开：`-2% 至 +2%`
- 中低开：`-5% 至 -2%`
- 大幅低开：`<= -5%`

10:10 前路径按开盘、10:10 收盘和 10:10 累计 VWAP分类：

- 高开延续：高开且 10:10 不低于开盘与 VWAP。
- 高开回落：高开且 10:10 低于开盘与 VWAP。
- 低开修复：低开且 10:10 高于开盘并不低于 VWAP。
- 低开延续下行：低开且 10:10 不高于开盘并低于 VWAP。
- 平开走强 / 平开走弱：平开样本按 10:10 相对开盘与 VWAP判断。
- 震荡：不满足以上方向组合。

### 统一退出和收益

- 主退出：入场日的下一交易日 `14:30-14:55` 成交额加权均价；所有执行方式共享。
- 敏感性观察：入场日收盘、下一交易日开盘、下一交易日收盘。
- 新买仓位遵守 T+1，不模拟入场日卖出。
- 每笔计算费用前后收益、MFE、MAE；汇总计算胜率、平均收益、等权累计、等权复合与路径最大回撤。
- 标准费用假设：佣金万 2.5、每笔最低 5 元；卖出印花税万 5；上海市场双边过户费万 0.1。报告费用前结果，并对假设保持可配置。
- 账户可成交性按本金 2 万元、1x 预算 1 万元、100 股一手另行计算；不能成交一手时只进入标准化研究，不计入实际账户可成交结果。

### 逐日账户累计修正

- “每笔独立复合”只比较单笔规则，不是账户累计；连续日报标的会在旧仓退出日与新仓入场日重叠，必须放入同一账户。
- 每个1x是账户50%，同日两条1x分别贡献 `0.5 × 单腿收益率`，总暴露最多2x/100%。价格差必须先除以该腿的起始价格，不能直接把不同价格股票的价差相加。
- 新仓入场日从实际成交代理价算到收盘；旧仓退出日从前一交易日收盘算到尾盘退出价。这样总收益自然包含隔夜跳空，且不会把B1成交前的价格变化算成持仓收益。
- 同日账户收益是所有持仓腿当日盈亏与当日费用之和；另用相同资金权重、相同入场时刻和相同退出窗口计算上证指数对照。
- 账本覆盖从最早入场日到最晚退出日的完整上证交易日序列；中间无新信号的持仓日仍按个股收盘标记，不能跳过隔夜收益。
- 上证分钟 `amount` 用于和日线做事实交叉核验；指数分钟 `volume` 单位与日线不直接可比，不参与价格代理。指数尾盘代理固定为 `14:31-14:55` 的25根分钟收盘均值。

### 保护样本

- 必须保留至少一笔“集合竞价买入更好”的样本，防止规则只解释 B1/B2 的优势。
- 必须保留至少一笔“等待确认避免或减少回撤”的样本。
- 若历史样本没有覆盖某种开盘位置与走势组合，报告写样本不足，不造示例收益。

## Recommendation

先按上述固定参数跑 1.0，不根据结果改阈值。若结果显示某个条件明显失真，下一轮只能在保留本轮结果的前提下提出 1.1，并用新样本或留出样本验证。

## Impact

- PRD: 增加同 1x 入场比较、正式 1x/2x 计划比较和实验拆单三条互不混淆的结论线。
- Design: 所有触发使用下一分钟开盘，主退出统一，账户颗粒度单独展示。
- Implementation: 阈值成为有名字的常量并由单测锁定；报告生成前不读取已有收益结论。
