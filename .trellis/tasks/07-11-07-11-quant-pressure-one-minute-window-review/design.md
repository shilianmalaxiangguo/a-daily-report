# Design: 一分钟量化压力案例与交易窗口复核

## Scope And Boundaries

本任务新增独立一分钟研究输入和分析模块，复用上一轮研究中的数学基础，但不改变 `quant_pressure_replay.v1` 五分钟契约，不进入正式日报生成链。

## Contracts / Data Flow

```text
通达信历史一分钟 OHLCV/成交额
  -> 冻结 fixture + 来源/哈希/日聚合校验
  -> 全日路径与客观下降段
  -> 竞争公式 + 起点敏感性
  -> 窗口结束时前缀证据
  -> 三例对照结论
  -> 单文件 HTML 研究汇报
```

一分钟 fixture 使用 `bar_period_minutes=1`，交易分钟按 `09:31-11:30`、`13:01-15:00` 固定为 `240` 根。通达信 bar 为分钟结束语义；两只个股用腾讯逐分钟累计量额做独立交叉核对，但 fixture 保存通达信单分钟 OHLCV/成交额。

### 公式层

- 事后形状层在同一对数价格响应上比较竞争公式，保留未舍入 AICc 与 ΔAICc。
- 普通对数 `a+b log(1+kt)` 与临界对数 `a+b[-log(1-t/T)]` 分开命名，避免曲率方向混淆。
- 有限时刻幂律作为主参数族；椭圆/根号、临界对数分别作为 `m≈0.5` 与 `m→0` 附近的视觉解释，但仍保留独立公式以检验经验外观。
- 单变化点分段模型解释阶段，不以其最佳断点替代盘中事件时间。
- 使用多个客观起点复算，报告模型结论是否依赖起点。

### 窗口层

每个窗口输出进入时已知事实、窗口内收益/振幅/斜率/曲率/量额、相对当时峰值回撤、窗口末压力状态，以及该状态在后续是否发展。用于判断窗口角色的结论只依赖窗口末及以前数据；后续发展单列为事后验收，不倒灌到当时判断。

## Compatibility / Migration

- 不迁移数据库，不覆盖正式日报与历史快照。
- HTML 继续使用原路径，便于用户当前浏览页刷新查看。
- 一分钟 fixture 与上一轮五分钟 fixture 分目录保存，避免粒度混用。

## Tradeoffs

- 选择通达信作为三例统一主源，可获得完整历史一分钟 OHLCV；代价是需要记录服务器与查询日，并用腾讯/既有五分钟事实做交叉核对。
- 选择独立研究模块而非把一分钟强行塞入五分钟运行时，避免把 6/4/3 bar 等阈值误缩短五倍。
- 三例只用于机制和时序校准，不足以估计命中率；后续扩大保护样本应另开任务。

## Rollback / Roll-forward

- 回滚只需恢复研究 HTML 并移除本任务新增研究文件，正式日报不受影响。
- 若本轮显示一分钟表象具有可重复的走前识别价值，下一步再建立跨日保护样本和单账户前瞻台账；未通过则保留为案例观察语言。
