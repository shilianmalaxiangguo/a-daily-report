# 使用入口

## 什么时候使用

- 用户比较当前杀跌与历史窗口，担心刻舟求剑。
- 历史样本提示反弹，但当前宽度、成交和主线结构仍有反证。
- 需要区分阶段反弹、首次收复和稳定修复。
- 需要解释“市场急流”类比，但不能把它固化为量化资金指标。

## 读取顺序

1. 先读 `wiki/交易思想/历史先验、实时结构与可用窗口.md`，使用稳定判断方法。
2. 需要核对 D 日人物、方法分歧和高空资料边界时，再读 `wiki/资料库/诺曼底D日气象预报分歧与决策窗口样本.md`。
3. 需要具体历史涨跌与恢复数字时，读取日期化研究，不从稳定节点猜测。
4. 需要当前资金方向、范围和阶段时，继续读取市场语言、宽度、板块和价格行为节点。

## 避免误用

- 来源卡是查证入口，不是日报自动知识条目。
- 当前节点只解释已经生成的结构事实和正式决定。
- “下一观察窗口”只列核对任务，不增加临时动作。
- 历史样本只给可能范围；来源明确的当前反证优先改变当前解释。
